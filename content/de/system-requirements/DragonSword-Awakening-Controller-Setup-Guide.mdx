DragonSword: Awakening ist ein Tag-Team-Action-Rollenspiel, bei dem sekundengenaues Timing darüber entscheidet, ob eure Komboketten gelingen oder abbrechen. Das Tag-Kampfsystem erfordert, dass ihr schnell zwischen drei Helden wechselt, Signalfähigkeiten auslöst und Wechselsignale innerhalb präziser Zeitfenster ausführt — und das alles, während ihr feindlichen Angriffen ausweicht und eure Frostanzeige verwaltet. Für viele Spieler bietet ein Controller ergonomischen Komfort und Vorteile durch das Muskelgedächtnis, die dieses anspruchsvolle Gameplay leichter handhabbar machen. Diese Anleitung behandelt alles, was ihr über die Controller-Unterstützung in DragonSword: Awakening wissen müsst, von der grundlegenden Einrichtung bis zur fortgeschrittenen Konfiguration für die Ausführung von Tag-Combos auf Wettbewerbsniveau.

Das Spiel unterstützt nativ Xbox-, PlayStation- und verschiedene Drittanbieter-Controller über Steam Input. Ob ihr das asymmetrische Stick-Layout von Xbox-Controllern oder das symmetrische Layout von PlayStation-Controllern bevorzugt, DragonSword: Awakening funktioniert mit beiden. Der Schlüssel liegt darin, die Tastenbelegung für die spezifischen Anforderungen des Tag-Team-Kampfes zu optimieren, anstatt die Standardkonfiguration zu verwenden, die für allgemeine Actionspiele entwickelt wurde.

## Native Controller-Unterstützung: Was sofort funktioniert

DragonSword: Awakening bietet native Controller-Unterstützung mit Standard-Tastenbelegungen für die gängigsten Controller-Typen. Das Spiel erkennt angeschlossene Controller automatisch und passt die Eingabeaufforderungen entsprechend an — Xbox-Controller zeigen Xbox-Tastensymbole, PlayStation-Controller zeigen PlayStation-Symbole.

### Standard-Tastenbelegung (Xbox-Controller)

| Aktion | Taste |
|--------|--------|
| Leichter Angriff | X |
| Schwerer Angriff / Fertigkeit | Y |
| Tag-Wechsel (Held 2) | LB |
| Tag-Wechsel (Held 3) | RB |
| Ausweichen | B |
| Interagieren / Bestätigen | A |
| Fertigkeit 1 | RT |
| Fertigkeit 2 | LT |
| Frostanzeigen-Explosion | RT + LT (gleichzeitig) |
| Menü / Pause | Start |
| Heldenauswahl | Zurück |

Das Standardlayout ist funktional, aber nicht für das Tag-Combo-System optimiert. Die Platzierung des Tag-Wechsels auf den Schultertasten (LB/RB) ist logisch, da der Tag-Wechsel während des Kampfes zugänglich sein muss, ohne den Daumen vom rechten Stick zu nehmen. Die Platzierung von Ausweichen auf B erfordert jedoch, dass ihr euren Daumen von den Aktionstasten bewegt, um auszuweichen, was eine Zeitlücke während der Combo-Ausführung erzeugt. Diese Lücke ist die häufigste Ursache für abgebrochene Combos bei Controller-Spielern.

### Standard-Tastenbelegung (PlayStation-Controller)

Das PlayStation-Layout spiegelt das Xbox-Layout mit den entsprechenden PlayStation-Tasten (Quadrat, Dreieck, L1, R1, Kreis, Kreuz, R2, L2) wider. Das gleiche Timing-Problem mit Ausweichen auf Kreis besteht. Die Empfehlungen in dieser Anleitung gelten für beide Controller-Typen, wobei die Tastenreferenzen für beide angegeben werden.

## Empfohlene Controller-Belegung für Tag-Combos

Das folgende Layout ist speziell für das Tag-Combo-System in DragonSword: Awakening optimiert. Es priorisiert schnellen Tag-Wechsel, reibungslose Integration des Ausweichens und minimale Daumenbewegung während Kampfsequenzen.

### Optimierte Tastenbelegung (Xbox)

| Aktion | Taste | Grund |
|--------|--------|--------|
| Leichter Angriff | X | Standardposition, häufig genutzte Aktion |
| Schwerer Angriff / Fertigkeit | Y | Standardposition, weniger häufig genutzt |
| Tag-Wechsel (Held 2) | LB | Schultertaste ermöglicht Tag-Wechsel ohne Daumenbewegung |
| Tag-Wechsel (Held 3) | RB | Wie oben |
| Ausweichen | Rechter Stick-Klick (R3) | Hält den Daumen beim Ausweichen auf dem Stick — keine Bewegungslücke |
| Interagieren / Bestätigen | A | Standardposition |
| Fertigkeit 1 | RT | Trigger für komfortable, wiederholte Nutzung |
| Fertigkeit 2 | LT | Trigger für komfortable, wiederholte Nutzung |
| Frostanzeigen-Explosion | RT + LT | Gleichzeitiges Drücken der Trigger, intuitiv für aktivierte Fähigkeiten |
| Tag-Auswahl (Held 1) | Zurück | Ermöglicht Rückkehr zum Haupthelden ohne Durchschalten |
| Menü / Pause | Start | Standardposition |

Die entscheidende Änderung ist das Verschieben von Ausweichen von B auf R3 (Klick auf den rechten Stick). Dies ermöglicht euch das Ausweichen, während ihr den Daumen auf dem rechten Stick für die Kamerasteuerung lasst, wodurch die Zeitlücke, die abgebrochene Combos verursacht, beseitigt wird. Dieses Layout benötigt etwa 2-3 Stunden Übung, um sich natürlich anzufühlen, aber sobald ihr euch daran gewöhnt habt, werdet ihr feststellen, dass die Ausführung von Tag-Combos deutlich flüssiger wird.

### Optimierte Tastenbelegung (PlayStation)

| Aktion | Taste |
|--------|--------|
| Leichter Angriff | Quadrat |
| Schwerer Angriff / Fertigkeit | Dreieck |
| Tag-Wechsel (Held 2) | L1 |
| Tag-Wechsel (Held 3) | R1 |
| Ausweichen | R3 |
| Interagieren / Bestätigen | Kreuz |
| Fertigkeit 1 | R2 |
| Fertigkeit 2 | L2 |
| Frostanzeigen-Explosion | R2 + L2 |
| Tag-Auswahl (Held 1) | Select |
| Menü / Pause | Start |

## Steam Input-Konfiguration

Steam Input ist ein leistungsstarkes Werkzeug, mit dem ihr die Controller-Belegung über die Einstellungen im Spiel hinaus anpassen könnt. So greift ihr auf die Steam Input-Konfiguration für DragonSword: Awakening zu:

1. Öffnet Steam und navigiert zu eurer Bibliothek.
2. Klickt mit der rechten Maustaste auf DragonSword: Awakening und wählt "Eigenschaften".
3. Navigiert zum Reiter "Controller".
4. Klickt auf "Controller-Konfiguration verwalten".
5. Wählt "Konfigurationen durchsuchen", um von der Community erstellte Layouts zu finden oder eure eigenen zu erstellen.

### Community-Konfigurationen

Mehrere Community-Mitglieder haben optimierte Controller-Konfigurationen für DragonSword: Awakening geteilt. Sucht nach Konfigurationen mit den Tags "Tag-Combo" oder "Wettkampf" für die besten Ergebnisse. Die beliebteste Community-Konfiguration zum Start ist "DSA Tag Combo Pro", die das oben beschriebene R3-Ausweichlayout zusammen mit zusätzlichen Optimierungen für Paddle-Controller implementiert.

### Benutzerdefinierte Konfiguration für Elite-/Pro-Controller

Wenn ihr einen Xbox Elite Series 2, DualSense Edge oder einen anderen Controller mit hinteren Paddles verwendet, weist den hinteren Paddles zusätzliche Tag-Funktionen zu. Die empfohlene Paddle-Belegung ist:

- **Linkes Paddle**: Tag-Wechsel (Held 1) — ermöglicht sofortige Rückkehr zum Haupthelden
- **Rechtes Paddle**: Ausweichen — Alternative zum R3-Ausweichen, wenn ihr das Ausweichen auf den Aktionstasten bevorzugt

Hintere Paddles machen es überflüssig, die Finger von ihren Standardpositionen zu bewegen, was die Ausführung von Tag-Combos so reibungslos wie möglich macht. Wenn ihr es mit dem Spielen auf Wettbewerbsniveau ernst meint, ist ein Controller mit hinteren Paddles eine lohnende Investition.

## Controller vs. Tastatur und Maus: Was ist besser?

Diese Frage taucht häufig in der DragonSword: Awakening-Community auf. Die ehrliche Antwort ist, dass beide Eingabemethoden praktikabel sind und die beste Wahl von euren persönlichen Vorlieben und Erfahrungen abhängt.

### Vorteile des Controllers

- **Ergonomischer Komfort**: Der Controller ist für längere Spielsitzungen bequemer und reduziert die Ermüdung von Händen und Handgelenken.
- **Analoge Bewegung**: Der linke Stick bietet 360-Grad-Bewegung mit variabler Geschwindigkeit, was für die Erkundung der offenen Welt und präzise Positionierung im Kampf nützlich ist.
- **Zugänglichkeit der Schultertasten**: Der Tag-Wechsel auf den Schultertasten fühlt sich natürlich und schnell an.
- **Vibrations-Feedback**: Haptisches Feedback bei Signalfähigkeits-Auslösern und Frostanzeigen-Aufladung liefert nützliche Timing-Hinweise.

### Vorteile von Tastatur und Maus

- **Präzise Kamerasteuerung**: Die Maussteuerung ist schneller und präziser als die Kamerasteuerung mit dem rechten Stick, was wichtig ist, um sich schnell bewegende Feinde während Tag-Combos zu verfolgen.
- **Mehr Tastenbelegungen**: Die Tastatur bietet Zugriff auf mehr Tasten, was dedizierte Belegungen für die Fertigkeiten jedes Helden ermöglicht, ohne auf Modifikatortasten angewiesen zu sein.
- **Keine Daumen-Bewegungslücke**: Ausweichen auf der Tastatur (typischerweise Leertaste) erfordert nicht, die Hände von den Kampftasten zu bewegen.
- **Potenzial für höhere Bildraten**: Bei einigen Hardwarekonfigurationen hat die Tastatureingabe eine geringere Latenz als die Controller-Eingabe über die Steam Input-Übersetzung.

### Empfehlung

Für die meisten Spieler ist der Controller die bessere Wahl für DragonSword: Awakening, da das Tag-Combo-System um den Wechsel mit den Schultertasten herum konzipiert ist und das Vibrations-Feedback einen echten Spielwert bietet. Tastatur und Maus sind vorzuziehen, wenn ihr aus dem PC-Actionspiel-Bereich kommt und die Maus-Kamerasteuerung bevorzugt. Beide Eingabemethoden sind auf höchstem Niveau konkurrenzfähig — der limitierende Faktor ist das Können des Spielers, nicht die Eingabemethode.

## Fehlerbehebung bei häufigen Controller-Problemen

### Controller wird nicht erkannt

Wenn euer Controller von DragonSword: Awakening nicht erkannt wird, überprüft zuerst, ob Steam ihn erkennt. Öffnet Steam > Einstellungen > Controller > Allgemeine Controller-Einstellungen und stellt sicher, dass euer Controller-Typ aktiviert ist. Wenn Steam den Controller erkennt, das Spiel aber nicht, versucht, Steam Input in den Eigenschaften des Spiels > Reiter Controller zu deaktivieren und wieder zu aktivieren.

### Eingabeverzögerung

Eingabeverzögerung bei Controllern wird normalerweise durch den Verarbeitungsaufwand von Steam Input verursacht. Wenn ihr eine spürbare Eingabeverzögerung (mehr als ~15 ms) feststellt, versucht, in den Controller-Einstellungen des Spiels von Steam Input auf den "Nativ"-Eingabemodus umzuschalten. Der native Modus umgeht die Übersetzungsschicht von Steam, unterstützt aber möglicherweise nicht alle Controller-Typen. Bei kabelgebundenen Controllern reduziert die Verwendung einer USB-Verbindung anstelle von Bluetooth die Eingabeverzögerung um etwa 5-10 ms.

### Tastensymbole zeigen falschen Controller-Typ an

Wenn das Spiel Xbox-Symbole anzeigt, obwohl ihr einen PlayStation-Controller verwendet (oder umgekehrt), schaltet die Einstellung "Controller-Typ" im Optionsmenü des Spiels um. DragonSword: Awakening ermöglicht es euch, manuell auszuwählen, welcher Eingabeaufforderungsstil angezeigt werden soll, unabhängig davon, welcher Controller angeschlossen ist.

## FAQ

### Unterstützt DragonSword Awakening die adaptiven Trigger des DualSense?

Zum Start unterstützt DragonSword: Awakening die grundlegende DualSense-Funktionalität (Tasten, Sticks, Gyro), nutzt aber nicht die adaptiven Trigger-Funktionen des DualSense-Controllers. Die Trigger funktionieren als standardmäßige analoge Trigger ohne Widerstands-Feedback. Hound13 könnte in einem zukünftigen Update Unterstützung für adaptive Trigger hinzufügen, was Widerstands-Feedback beim Aufladen der Frostanzeige und bei Fertigkeitsaktivierungen bieten würde.

### Kann ich einen Nintendo Switch Pro Controller verwenden?

Ja, der Switch Pro Controller funktioniert über Steam Input. Die Tastenbelegung ähnelt dem Xbox-Layout (A/B/X/Y-Positionen sind im Vergleich zu Xbox vertauscht, aber Steam Input übernimmt die Zuordnung automatisch). Der Switch Pro Controller unterstützt keine Vibration in DragonSword: Awakening über Steam Input. Für das grundlegende Gameplay funktioniert er gut, aber Wettkampfspieler bevorzugen möglicherweise einen Controller mit mehr Funktionen.

### Wird Gyro-Zielen unterstützt?

DragonSword: Awakening unterstützt zum Start kein Gyro-unterstütztes Zielen. Die Gyro-Sensoren des PlayStation DualSense und Switch Pro Controllers werden vom Spiel nicht genutzt. Wenn ihr Gyro-Steuerung bevorzugt, könnt ihr den "Gyro to Mouse"-Modus von Steam Input aktivieren, aber das ist eine Notlösung, die sich für ein Third-Person-Action-Rollenspiel möglicherweise nicht optimal anfühlt.

### Wie wechsle ich mitten im Spiel zwischen Controller und Tastatur?

DragonSword: Awakening wechselt die Eingabe automatisch basierend auf dem zuletzt verwendeten Gerät. Wenn ihr euren Controller in die Hand nehmt und eine Taste drückt, wechselt das Spiel in den Controller-Modus. Wenn ihr eine Taste auf der Tastatur drückt, wechselt es zurück. Dieser Hot-Swap funktioniert in den meisten Fällen nahtlos, obwohl die UI-Eingabeaufforderungen während des Übergangs kurz flackern können. Weitere Informationen zu Eingabeoptionen findet ihr in unserem [Systemanforderungen-Leitfaden](/de/system-requirements/system-requirements/).

### Welchen Controller verwenden professionelle DragonSword Awakening-Spieler?

Da das Spiel gerade erst gestartet ist, bildet sich eine Wettkampfszene noch heraus. Frühe Community-Leader neigen dazu, Xbox Elite Series 2-Controller wegen des Vorteils der hinteren Paddles oder Standard-DualSense-Controller wegen des ergonomischen Designs zu verwenden. Der wichtigste Faktor ist nicht das spezifische Controller-Modell, sondern die Konfiguration der Tastenbelegung — das in dieser Anleitung beschriebene R3-Ausweichlayout entwickelt sich zum Community-Standard für die Ausführung von Tag-Combos auf Wettbewerbsniveau.
