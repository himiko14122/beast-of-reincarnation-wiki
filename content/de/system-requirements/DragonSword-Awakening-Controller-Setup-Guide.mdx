DragonSword: Awakening ist ein Tag-Team-Action-RPG, in dem Bruchteile von Sekunden darüber entscheiden, ob deine Kombo-Ketten gelingen oder abreißen. Das Tag-Kampfsystem erfordert, dass du schnell zwischen drei Helden wechselst, Signal-Skills auslöst und Switching Signals innerhalb präziser Zeitfenster ausführst – während du gleichzeitig feindlichen Angriffen ausweichst und deine Frost-Anzeige verwaltest. Für viele Spieler bietet ein Controller den ergonomischen Komfort und die Vorteile des Muskelgedächtnisses, die dieses anspruchsvolle Gameplay besser handhabbar machen. Dieser Leitfaden deckt alles ab, was du über die Controller-Unterstützung in DragonSword: Awakening wissen musst, von der grundlegenden Einrichtung bis hin zur fortgeschrittenen Konfiguration für Kombo-Ausführung auf Wettbewerbsniveau.

Das Spiel unterstützt nativ Xbox-, PlayStation- und verschiedene Drittanbieter-Controller über Steam Input. Egal, ob du das asymmetrische Stick-Layout von Xbox-Controllern oder das symmetrische Layout von PlayStation-Controllern bevorzugst, DragonSword: Awakening funktioniert mit beiden. Der Schlüssel liegt darin, das Button-Layout so zu konfigurieren, dass es für die spezifischen Anforderungen des Tag-Team-Kampfes optimiert ist, anstatt die für allgemeine Action-Spiele konzipierte Standardkonfiguration zu verwenden.

## Native Controller-Unterstützung: Was funktioniert sofort

DragonSword: Awakening bietet native Controller-Unterstützung mit Standard-Button-Belegungen für die gängigsten Controller-Typen. Das Spiel erkennt automatisch verbundene Controller und passt die Eingabeaufforderungen entsprechend an – Xbox-Controller zeigen Xbox-Button-Symbole, PlayStation-Controller zeigen PlayStation-Symbole.

### Standard-Button-Layout (Xbox-Controller)

| Aktion | Button |
|--------|--------|
| Leichter Angriff | X |
| Schwerer Angriff / Skill | Y |
| Tag-Wechsel (Held 2) | LB |
| Tag-Wechsel (Held 3) | RB |
| Ausweichen | B |
| Interagieren / Bestätigen | A |
| Skill 1 | RT |
| Skill 2 | LT |
| Frost-Anzeige-Burst | RT + LT (gleichzeitig) |
| Menü / Pause | Start |
| Heldenauswahl | Back |

Das Standardlayout ist funktional, aber nicht für das Tag-Kombosystem optimiert. Die Platzierung des Tag-Wechsels auf den Schultertasten (LB/RB) ist logisch, da der Tag-Wechsel während des Kampfes zugänglich sein muss, ohne den Daumen vom rechten Stick zu nehmen. Allerdings erfordert die Platzierung von Ausweichen auf B, dass du den Daumen von den Face-Buttons wegbewegst, um auszuweichen, was eine Zeitlücke während der Kombo-Ausführung erzeugt. Diese Lücke ist die häufigste Ursache für abgebrochene Kombos bei Controller-Spielern.

### Standard-Button-Layout (PlayStation-Controller)

Das PlayStation-Layout spiegelt das Xbox-Layout mit den entsprechenden PlayStation-Buttons (Square, Triangle, L1, R1, Circle, Cross, R2, L2). Das gleiche Timing-Problem mit Ausweichen auf Circle gilt ebenfalls. Die Empfehlungen in diesem Leitfaden gelten für beide Controller-Typen, mit Button-Referenzen für beide.

## Empfohlenes Controller-Layout für Tag-Kombos

Das folgende Layout ist speziell für das Tag-Kombosystem in DragonSword: Awakening optimiert. Es priorisiert schnelles Tag-Wechseln, reibungslose Ausweich-Integration und minimale Daumenbewegung während der Kampfkombinationen.

### Optimiertes Button-Layout (Xbox)

| Aktion | Button | Grund |
|--------|--------|--------|
| Leichter Angriff | X | Standardposition, häufig verwendete Aktion |
| Schwerer Angriff / Skill | Y | Standardposition, weniger häufig verwendet |
| Tag-Wechsel (Held 2) | LB | Schultertaste ermöglicht Tag-Wechsel im Kampf ohne Daumenbewegung |
| Tag-Wechsel (Held 3) | RB | Wie oben |
| Ausweichen | Right Stick Click (R3) | Daumen bleibt beim Ausweichen auf dem Stick – keine Bewegungslücke |
| Interagieren / Bestätigen | A | Standardposition |
| Skill 1 | RT | Trigger für komfortable wiederholte Nutzung |
| Skill 2 | LT | Trigger für komfortable wiederholte Nutzung |
| Frost-Anzeige-Burst | RT + LT | Gleichzeitiger Triggerdruck, intuitiv für aktivierte Fähigkeiten |
| Tag-Auswahl (Held 1) | Back | Ermöglicht die Rückkehr zum Primärhelden ohne Durchschalten |
| Menü / Pause | Start | Standardposition |

Die entscheidende Änderung ist das Verschieben von Ausweichen von B auf R3 (rechter Stick-Klick). Dies ermöglicht es dir, auszuweichen, während dein Daumen auf dem rechten Stick für die Kamerasteuerung bleibt, wodurch die Zeitlücke eliminiert wird, die abgebrochene Kombos verursacht. Dieses Layout benötigt etwa 2-3 Stunden Übung, um sich natürlich anzufühlen, aber sobald du dich angepasst hast, wirst du feststellen, dass die Ausführung von Tag-Kombos deutlich flüssiger wird.

### Optimiertes Button-Layout (PlayStation)

| Aktion | Button |
|--------|--------|
| Leichter Angriff | Square |
| Schwerer Angriff / Skill | Triangle |
| Tag-Wechsel (Held 2) | L1 |
| Tag-Wechsel (Held 3) | R1 |
| Ausweichen | R3 |
| Interagieren / Bestätigen | Cross |
| Skill 1 | R2 |
| Skill 2 | L2 |
| Frost-Anzeige-Burst | R2 + L2 |
| Tag-Auswahl (Held 1) | Select |
| Menü / Pause | Start |

## Steam-Input-Konfiguration

Steam Input ist ein leistungsstarkes Werkzeug, mit dem du Controller-Belegungen über das hinaus anpassen kannst, was die In-Game-Einstellungen bieten. So greifst du auf die Steam-Input-Konfiguration für DragonSword: Awakening zu:

1. Öffne Steam und navigiere zu deiner Bibliothek.

2. Klicke mit der rechten Maustaste auf DragonSword: Awakening und wähle „Eigenschaften".

3. Navigiere zum Tab „Controller".

4. Klicke auf „Controller-Konfiguration für dieses Spiel verwalten".

5. Wähle „Konfigurationen durchsuchen", um von der Community erstellte Layouts zu finden, oder erstelle deine eigene.

### Community-Konfigurationen

Mehrere Community-Mitglieder haben optimierte Controller-Konfigurationen für DragonSword: Awakening geteilt. Suche nach Konfigurationen mit den Tags „Tag-Kombo" oder „Wettbewerb", um die besten Ergebnisse zu erzielen. Die beliebteste Community-Konfiguration zum Start ist „DSA Tag Combo Pro", die das oben beschriebene R3-Ausweich-Layout zusammen mit zusätzlichen Optimierungen für Paddle-Controller implementiert.

### Benutzerdefinierte Konfiguration für Elite/Pro-Controller

Wenn du einen Xbox Elite Series 2, DualSense Edge oder einen anderen Controller mit hinteren Paddles verwendest, weise die hinteren Paddles zusätzlichen Tag-Funktionen zu. Die empfohlene Paddle-Belegung ist:

- **Linkes Paddle**: Tag-Wechsel (Held 1) – ermöglicht sofortige Rückkehr zum Primärhelden

- **Rechtes Paddle**: Ausweichen – Alternative zum R3-Ausweichen, wenn du Face-Button-Ausweichen bevorzugst

Hintere Paddles eliminieren die Notwendigkeit, Finger aus ihren Standardpositionen zu bewegen, was die Tag-Kombo-Ausführung so reibungslos wie möglich macht. Wenn du es mit Wettbewerbsspiel ernst meinst, ist ein Controller mit hinteren Paddles eine lohnende Investition.

## Controller vs. Tastatur und Maus: Was ist besser?

Diese Frage taucht in der DragonSword: Awakening-Community häufig auf. Die ehrliche Antwort ist, dass beide Eingabemethoden praktikabel sind, und die beste Wahl hängt von deinen persönlichen Vorlieben und Erfahrungen ab.

### Vorteile des Controllers

- **Ergonomischer Komfort**: Der Controller ist für längere Spielsitzungen komfortabler und reduziert Hand- und Handgelenk-Ermüdung.

- **Analoge Bewegung**: Der linke Stick bietet 360-Grad-Bewegung mit variabler Geschwindigkeit, was für Open-World-Erkundung und präzise Positionierung im Kampf nützlich ist.

- **Zugänglichkeit der Schultertasten**: Der Tag-Wechsel auf den Schultertasten fühlt sich natürlich und schnell an.

- **Vibrations-Feedback**: Haptisches Feedback bei Signal-Skill-Auslösungen und Frost-Anzeigen-Ladungen bietet nützliche Timing-Hinweise.

### Vorteile von Tastatur und Maus

- **Präzise Kamerasteuerung**: Maus-Blick ist schneller und präziser als die Kamerasteuerung mit dem rechten Stick, was wichtig ist, um sich schnell bewegende Feinde während Tag-Kombos zu verfolgen.

- **Mehr Tastenbelegungen**: Die Tastatur bietet Zugriff auf mehr Tasten, was dedizierte Belegungen für die Skills jedes Helden ermöglicht, ohne auf Modifikator-Tasten angewiesen zu sein.

- **Keine Daumenbewegungslücke**: Ausweichen auf der Tastatur (typischerweise Leertaste) erfordert keine Bewegung der Hände von den Kampf-Tasten.

- **Höheres FPS-Potenzial**: Bei einigen Hardware-Konfigurationen hat die Tastatureingabe eine geringere Latenz als die Controller-Eingabe durch die Steam-Input-Übersetzung.

### Empfehlung

Für die meisten Spieler ist der Controller die bessere Wahl für DragonSword: Awakening, da das Tag-Kombosystem um das Schultertasten-Wechseln herum konzipiert ist und das Vibrations-Feedback echten Gameplay-Wert bietet. Tastatur und Maus sind vorzuziehen, wenn du aus dem Bereich der PC-Action-Spiele kommst und Maus-Blick-Kamerasteuerung bevorzugst. Beide Eingaben sind auf höchstem Niveau wettbewerbsfähig – der limitierende Faktor ist die Spielerfähigkeit, nicht die Eingabemethode.

## Fehlerbehebung bei häufigen Controller-Problemen

### Controller wird nicht erkannt

Wenn dein Controller von DragonSword: Awakening nicht erkannt wird, überprüfe zunächst, ob Steam ihn erkennt. Öffne Steam > Einstellungen > Controller > Allgemeine Controller-Einstellungen und stelle sicher, dass dein Controller-Typ aktiviert ist. Wenn Steam den Controller erkennt, das Spiel jedoch nicht, versuche, Steam Input im Tab Eigenschaften > Controller des Spiels zu deaktivieren und wieder zu aktivieren.

### Eingabeverzögerung

Eingabeverzögerung bei Controllern wird normalerweise durch den Verarbeitungsaufwand von Steam Input verursacht. Wenn du eine spürbare Eingabeverzögerung feststellst (mehr als ~15ms), versuche, in den Controller-Einstellungen des Spiels vom Steam-Input-Modus auf den „Native"-Eingabemodus zu wechseln. Der Native-Modus umgeht die Übersetzungsschicht von Steam, unterstützt jedoch möglicherweise nicht alle Controller-Typen. Bei kabelgebundenen Controllern reduziert die Verwendung einer USB-Verbindung anstelle von Bluetooth die Eingabeverzögerung um etwa 5-10ms.

### Falsche Button-Symbole werden angezeigt

Wenn das Spiel Xbox-Symbole anzeigt, obwohl du einen PlayStation-Controller verwendest (oder umgekehrt), schalte die Einstellung „Controller-Typ" im In-Game-Optionsmenü um. DragonSword: Awakening ermöglicht es dir, manuell auszuwählen, welcher Symbol-Stil angezeigt werden soll, unabhängig davon, welcher Controller angeschlossen ist.

## FAQ

### Unterstützt DragonSword Awakening die adaptiven Trigger des DualSense?

Zum Start unterstützt DragonSword: Awakening die grundlegende DualSense-Funktionalität (Buttons, Sticks, Gyro), nutzt jedoch nicht die adaptiven Trigger-Funktionen des DualSense-Controllers. Die Trigger funktionieren als Standard-Analog-Trigger ohne Widerstands-Feedback. Hound13 könnte in einem zukünftigen Update Unterstützung für adaptive Trigger hinzufügen, die Widerstands-Feedback beim Laden der Frost-Anzeige und Skill-Aktivierungen bieten würde.

### Kann ich einen Nintendo Switch Pro Controller verwenden?

Ja, der Switch Pro Controller funktioniert über Steam Input. Das Button-Layout ähnelt dem Xbox-Layout (A/B/X/Y-Positionen sind im Vergleich zu Xbox vertauscht, aber Steam Input übernimmt die Zuordnung automatisch). Der Switch Pro Controller unterstützt keine Vibration in DragonSword: Awakening über Steam Input. Für grundlegendes Gameplay funktioniert er gut, aber Wettbewerbsspieler bevorzugen möglicherweise einen Controller mit mehr Funktionen.

### Wird Gyro-Zielen unterstützt?

DragonSword: Awakening unterstützt zum Start kein Gyro-unterstütztes Zielen. Die Gyro-Sensoren des PlayStation DualSense und Switch Pro Controller werden vom Spiel nicht genutzt. Wenn du Gyro-Steuerung bevorzugst, kannst du den Modus „Gyro zu Maus" von Steam Input aktivieren, aber dies ist eine Umgehungslösung, die sich für ein Third-Person-Action-RPG möglicherweise nicht optimal anfühlt.

### Wie wechsle ich mitten im Spiel zwischen Controller und Tastatur?

DragonSword: Awakening wechselt die Eingabe automatisch basierend auf dem letzten Gerät, das eine Eingabe erhalten hat. Wenn du deinen Controller in die Hand nimmst und einen Button drückst, wechselt das Spiel in den Controller-Modus. Wenn du eine Taste auf der Tastatur drückst, wechselt es zurück. Dieses Hot-Swapping funktioniert in den meisten Fällen nahtlos, obwohl die UI-Symbole während des Übergangs kurz flackern können. Für weitere Informationen zu Eingabeoptionen siehe unseren [Systemanforderungen-Leitfaden](/en/system-requirements/system-requirements/).

### Welchen Controller verwenden professionelle DragonSword Awakening-Spieler?

Da das Spiel gerade erst erschienen ist, formiert sich erst eine Wettbewerbs-Szene. Frühe Community-Vorreiter verwenden tendenziell Xbox Elite Series 2-Controller wegen des Vorteils der hinteren Paddles, oder standardmäßige DualSense-Controller wegen des ergonomischen Designs. Der wichtigste Faktor ist nicht das spezifische Controller-Modell, sondern die Button-Layout-Konfiguration – das in diesem Leitfaden beschriebene R3-Ausweich-Layout wird zum Community-Standard für die Ausführung von Wettbewerbs-Tag-Kombos. Für weitere Kampf-Tipps siehe unseren [Kampfsystem-Leitfaden](/en/guides/combat-system-guide/).
