DragonSword: Awakening은 순간적인 타이밍이 콤보 연결을 성공시키거나 끊어지게 하는 태그 팀 액션 RPG입니다. 태그 전투 시스템은 적의 공격을 피하고 프로스트 게이지를 관리하는 동시에 세 명의 영웅을 빠르게 전환하고, 시그널 스킬을 발동시키며, 정확한 타이밍 안에 스위칭 시그널을 실행해야 합니다. 많은 플레이어에게 컨트롤러는 이러한 고난도 플레이를 더 쉽게 만들어주는 인체공학적 편안함과 근육 기억의 이점을 제공합니다. 이 가이드는 DragonSword: Awakening의 컨트롤러 지원에 대한 모든 것, 기본 설정부터 경쟁력 있는 태그 콤보 실행을 위한 고급 구성까지 다룹니다.

## 기본 컨트롤러 지원: 바로 사용 가능한 기능

DragonSword: Awakening은 가장 일반적인 컨트롤러 유형에 대한 기본 버튼 매핑과 함께 기본 컨트롤러 지원을 제공합니다. 게임은 연결된 컨트롤러를 자동으로 감지하고 이에 따라 입력 프롬프트를 전환합니다. Xbox 컨트롤러는 Xbox 버튼 아이콘을, PlayStation 컨트롤러는 PlayStation 아이콘을 표시합니다.

### 기본 버튼 레이아웃 (Xbox 컨트롤러)

| 동작 | 버튼 |
|--------|--------|
| 약공격 | X |
| 강공격 / 스킬 | Y |
| 태그 전환 (영웅 2) | LB |
| 태그 전환 (영웅 3) | RB |
| 회피 | B |
| 상호작용 / 확인 | A |
| 스킬 1 | RT |
| 스킬 2 | LT |
| 프로스트 게이지 버스트 | RT + LT (동시 입력) |
| 메뉴 / 일시정지 | Start |
| 영웅 선택 | Back |

기본 레이아웃은 기능적이지만 태그 콤보 시스템에 최적화되어 있지는 않습니다. 숄더 버튼(LB/RB)에 태그 전환을 배치한 것은 전투 중에 오른쪽 스틱에서 엄지를 떼지 않고도 태그 전환에 접근할 수 있어 논리적입니다. 하지만 회피가 B 버튼에 배치되어 있어 회피하려면 페이스 버튼에서 엄지를 움직여야 하므로 콤보 실행 중 타이밍 공백이 발생합니다. 이 공백은 컨트롤러 플레이어에게 콤보가 끊기는 가장 흔한 원인입니다.

### 기본 버튼 레이아웃 (PlayStation 컨트롤러)

PlayStation 레이아웃은 해당 PlayStation 버튼(□, △, L1, R1, ○, ×, R2, L2)으로 Xbox 레이아웃을 반영합니다. 회피가 ○ 버튼에 배치되어 발생하는 동일한 타이밍 문제가 적용됩니다. 이 가이드의 권장 사항은 두 컨트롤러 유형 모두에 적용되며, 버튼 참조는 둘 다 제공됩니다.

## 태그 콤보를 위한 권장 컨트롤러 레이아웃

다음 레이아웃은 DragonSword: Awakening의 태그 콤보 시스템에 특별히 최적화되었습니다. 빠른 태그 전환, 부드러운 회피 통합, 전투 중 최소한의 엄지 움직임을 우선시합니다.

### 최적화된 버튼 레이아웃 (Xbox)

| 동작 | 버튼 | 이유 |
|--------|--------|--------|
| 약공격 | X | 표준 위치, 사용 빈도가 높은 동작 |
| 강공격 / 스킬 | Y | 표준 위치, 사용 빈도가 낮음 |
| 태그 전환 (영웅 2) | LB | 숄더 버튼으로 엄지 이동 없이 태그 가능 |
| 태그 전환 (영웅 3) | RB | 위와 동일 |
| 회피 | 오른쪽 스틱 클릭 (R3) | 회피 시에도 스틱에 엄지 유지 — 이동 공백 없음 |
| 상호작용 / 확인 | A | 표준 위치 |
| 스킬 1 | RT | 편안한 반복 사용을 위한 트리거 |
| 스킬 2 | LT | 편안한 반복 사용을 위한 트리거 |
| 프로스트 게이지 버스트 | RT + LT | 동시 트리거 입력, 활성화 능력에 직관적 |
| 태그 선택 (영웅 1) | Back | 순환 없이 주 영웅으로 복귀 가능 |
| 메뉴 / 일시정지 | Start | 표준 위치 |

중요한 변경 사항은 회피를 B에서 R3(오른쪽 스틱 클릭)로 옮기는 것입니다. 이렇게 하면 카메라 제어를 위해 오른쪽 스틱에 엄지를 유지하면서 회피할 수 있어 콤보가 끊기는 타이밍 공백을 제거합니다. 이 레이아웃에 적응하는 데 약 2~3시간의 연습이 필요하지만, 일단 적응하면 태그 콤보 실행이 훨씬 더 부드러워집니다.

| 약공격 | □ |
| 강공격 / 스킬 | △ |
| 태그 전환 (영웅 2) | L1 |
| 태그 전환 (영웅 3) | R1 |
| 회피 | R3 |
| 상호작용 / 확인 | × |
| 스킬 1 | R2 |
| 스킬 2 | L2 |

## Steam Input 구성

Steam Input은 게임 내 설정 이상으로 컨트롤러 매핑을 사용자 정의할 수 있는 강력한 도구입니다. DragonSword: Awakening의 Steam Input 구성에 접근하려면:

1. Steam을 열고 라이브러리로 이동합니다.
2. DragonSword: Awakening을 마우스 오른쪽 버튼으로 클릭하고 "속성"을 선택합니다.
3. "컨트롤러" 탭으로 이동합니다.
4. "게임 컨트롤러 구성 관리"를 클릭합니다.
5. "구성 찾아보기"를 선택하여 커뮤니티 제작 레이아웃을 찾거나 직접 만듭니다.

### 커뮤니티 구성

여러 커뮤니티 회원이 DragonSword: Awakening을 위한 최적화된 컨트롤러 구성을 공유했습니다. "태그 콤보" 또는 "경쟁" 태그가 붙은 구성을 검색하면 최상의 결과를 얻을 수 있습니다. 출시 시점 기준 가장 인기 있는 커뮤니티 구성은 "DSA Tag Combo Pro"로, 위에서 설명한 R3 회피 레이아웃과 패들 컨트롤러를 위한 추가 조정 사항을 구현합니다.

### Elite/Pro 컨트롤러를 위한 사용자 정의 구성

Xbox Elite Series 2, DualSense Edge 또는 후면 패들이 있는 다른 컨트롤러를 사용하는 경우, 후면 패들에 추가 태그 기능을 할당하십시오. 권장 패들 매핑은 다음과 같습니다:

- **왼쪽 패들**: 태그 전환 (영웅 1) — 주 영웅으로 즉시 복귀 가능
- **오른쪽 패들**: 회피 — 페이스 버튼 회피를 선호하는 경우 R3 회피의 대안

후면 패들은 기본 위치에서 손가락을 움직일 필요를 없애 태그 콤보 실행을 최대한 부드럽게 만듭니다. 경쟁력 있는 수준의 플레이를 진지하게 고려한다면, 후면 패들이 있는 컨트롤러는 투자할 가치가 있습니다.

## 컨트롤러 vs 키보드 및 마우스: 어느 것이 더 나은가요?

이 질문은 DragonSword: Awakening 커뮤니티에서 자주 등장합니다. 솔직한 답변은 두 입력 방식 모두 실행 가능하며, 최선의 선택은 개인 선호도와 경험에 달려 있다는 것입니다.

### 컨트롤러의 장점

- **인체공학적 편안함**: 컨트롤러는 장시간 플레이 세션에 더 편안하여 손과 손목의 피로를 줄여줍니다.
- **아날로그 이동**: 왼쪽 스틱은 가변 속도로 360도 이동을 제공하여 오픈 월드 탐험과 전투 중 정밀한 위치 선정에 유용합니다.
- **숄더 버튼 접근성**: 숄더 버튼의 태그 전환이 자연스럽고 빠르게 느껴집니다.
- **진동 피드백**: 시그널 스킬 발동 및 프로스트 게이지 충전 시 햅틱 피드백이 유용한 타이밍 신호를 제공합니다.

### 키보드 및 마우스의 장점

- **정밀한 카메라 제어**: 마우스 시점 조작이 오른쪽 스틱 카메라 제어보다 빠르고 정밀하여 태그 콤보 중 빠르게 움직이는 적을 추적하는 데 중요합니다.
- **더 많은 키 바인딩**: 키보드는 더 많은 키에 접근할 수 있어 수정 키에 의존하지 않고 각 영웅의 스킬에 전용 바인딩을 할당할 수 있습니다.
- **엄지 이동 공백 없음**: 키보드 회피(일반적으로 스페이스바)는 전투 키에서 손을 움직일 필요가 없습니다.
- **더 높은 프레임 속도 가능성**: 일부 하드웨어 구성에서 키보드 입력은 Steam Input 변환을 통한 컨트롤러 입력보다 지연 시간이 짧습니다.

### 권장 사항

대부분의 플레이어에게 컨트롤러는 DragonSword: Awakening에 더 나은 선택입니다. 태그 콤보 시스템이 숄더 버튼 전환을 중심으로 설계되었고 진동 피드백이 실제 게임 플레이 가치를 제공하기 때문입니다. PC 액션 게임 배경을 가지고 있고 마우스 시점 카메라 제어를 선호한다면 키보드와 마우스가 더 좋습니다. 두 입력 방식 모두 최고 수준에서 경쟁력이 있습니다. 제한 요소는 입력 방식이 아니라 플레이어의 실력입니다.

## 일반적인 컨트롤러 문제 해결

### 컨트롤러가 감지되지 않음

DragonSword: Awakening에서 컨트롤러가 감지되지 않으면 먼저 Steam에서 감지하는지 확인하십시오. Steam > 설정 > 컨트롤러 > 일반 컨트롤러 설정을 열고 컨트롤러 유형이 선택되어 있는지 확인하십시오. Steam이 컨트롤러를 감지하지만 게임이 감지하지 못하는 경우, 게임의 속성 > 컨트롤러 탭에서 Steam Input을 비활성화했다가 다시 활성화해 보십시오.

### 입력 지연

컨트롤러의 입력 지연은 일반적으로 Steam Input 처리 오버헤드로 인해 발생합니다. 눈에 띄는 입력 지연(약 15ms 이상)이 발생하면 게임의 컨트롤러 설정에서 Steam Input을 "Native" 입력 모드로 전환해 보십시오. Native 모드는 Steam의 변환 계층을 우회하지만 모든 컨트롤러 유형을 지원하지 않을 수 있습니다. 유선 컨트롤러의 경우 Bluetooth 대신 USB 연결을 사용하면 입력 지연이 약 5-10ms 감소합니다.

### 잘못된 컨트롤러 유형의 버튼 프롬프트 표시

PlayStation 컨트롤러를 사용할 때 게임에 Xbox 프롬프트가 표시되거나 그 반대의 경우, 게임 내 옵션 메뉴에서 "컨트롤러 유형" 설정을 전환하십시오. DragonSword: Awakening은 연결된 컨트롤러에 관계없이 표시할 프롬프트 스타일을 수동으로 선택할 수 있게 해줍니다.

## FAQ

### DragonSword Awakening은 DualSense 적응형 트리거를 지원하나요?

출시 시점 기준으로 DragonSword: Awakening은 기본 DualSense 기능(버튼, 스틱, 자이로)을 지원하지만 DualSense 컨트롤러의 적응형 트리거 기능은 활용하지 않습니다. 트리거는 저항 피드백 없이 표준 아날로그 트리거로 작동합니다. Hound13은 향후 업데이트에서 적응형 트리거 지원을 추가할 수 있으며, 이 경우 프로스트 게이지 충전 및 스킬 활성화 시 저항 피드백을 제공할 것입니다.

### Nintendo Switch Pro 컨트롤러를 사용할 수 있나요?

네, Switch Pro 컨트롤러는 Steam Input을 통해 작동합니다. 버튼 레이아웃은 Xbox 레이아웃과 유사합니다(A/B/X/Y 위치가 Xbox와 바뀌어 있지만 Steam Input이 자동으로 매핑을 처리합니다). Switch Pro 컨트롤러는 Steam Input을 통한 DragonSword: Awakening에서 진동을 지원하지 않습니다. 기본적인 게임 플레이에는 잘 작동하지만, 경쟁적인 플레이어는 더 많은 기능을 갖춘 컨트롤러를 선호할 수 있습니다.

### 자이로 조준이 지원되나요?

DragonSword: Awakening은 출시 시점 기준으로 자이로 보조 조준을 지원하지 않습니다. PlayStation DualSense 및 Switch Pro 컨트롤러의 자이로 센서는 게임에서 활용되지 않습니다. 자이로 컨트롤을 선호하는 경우 Steam Input의 "자이로를 마우스로" 모드를 활성화할 수 있지만, 이는 임시방편이며 3인칭 액션 RPG에 최적화된 느낌이 아닐 수 있습니다.

### 게임 중에 컨트롤러와 키보드를 어떻게 전환하나요?

DragonSword: Awakening은 마지막으로 입력을 받은 장치에 따라 자동으로 입력을 전환합니다. 컨트롤러를 집어 버튼을 누르면 게임이 컨트롤러 모드로 전환됩니다. 키보드의 키를 누르면 다시 전환됩니다. 이 핫 스와핑은 대부분의 경우 원활하게 작동하지만, 전환 중에 UI 프롬프트가 잠시 깜박일 수 있습니다. 입력 옵션에 대한 자세한 내용은 [시스템 요구 사항 가이드](/ko/system-requirements/system-requirements/)를 참조하십시오.

### DragonSword Awakening 프로 선수들은 어떤 컨트롤러를 사용하나요?

게임이 막 출시되었기 때문에 경쟁 장면은 아직 형성 중입니다. 초기 커뮤니티 리더들은 후면 패들의 이점 때문에 Xbox Elite Series 2 컨트롤러를 사용하거나, 인체공학적 디자인 때문에 표준 DualSense 컨트롤러를 사용하는 경향이 있습니다. 가장 중요한 요소는 특정 컨트롤러 모델이 아니라 버튼 레이아웃 구성입니다. 이 가이드에서 설명하는 R3 회피 레이아웃은 경쟁적인 태그 콤보 실행을 위한 커뮤니티 표준이 되고 있습니다. 더 많은 전투 팁을 보려면 [전투 시스템 가이드](/ko/guides/combat-system-guide/)를 참조하십시오.
