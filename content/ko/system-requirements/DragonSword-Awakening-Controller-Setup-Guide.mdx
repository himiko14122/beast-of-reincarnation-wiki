DragonSword: Awakening은 태그팀 액션 RPG로, 순식간에 결정되는 타이밍에 따라 콤보 체인이 연결되거나 끊어집니다. 태그 전투 시스템에서는 세 명의 영웅을 빠르게 교대하고, 시그널 스킬을 발동하며, 정확한 타이밍 윈도우 내에서 스위칭 시그널을 실행해야 합니다 — 동시에 적의 공격을 회피하고 프로스트 게이지를 관리해야 합니다. 많은 플레이어들에게 컨트롤러는 인체공학적 편안함과 근육 기억 이점을 제공하여 까다로운 게임플레이를 더 관리하기 쉽게 만듭니다. 이 가이드는 기본 설정부터 경쟁 수준의 태그 콤보 실행을 위한 고급 구성까지, DragonSword: Awakening의 컨트롤러 지원에 대해 알아야 할 모든 것을 다룹니다.

이 게임은 Steam Input을 통해 Xbox, PlayStation 및 다양한 서드파티 컨트롤러를 기본적으로 지원합니다. Xbox 컨트롤러의 비대칭 스틱 배치를 선호하든, PlayStation 컨트롤러의 대칭 배치를 선호하든, DragonSword: Awakening은 둘 다에서 작동합니다. 핵심은 일반 액션 게임을 위해 설계된 기본 구성 대신, 태그팀 전투의 특정 요구사항에 최적화하도록 버튼 배치를 구성하는 것입니다.

## 기본 컨트롤러 지원: 별도 설정 없이 작동하는 것

DragonSword: Awakening은 가장 일반적인 컨트롤러 유형에 대한 기본 버튼 매핑과 함께 기본 컨트롤러 지원을 제공합니다. 게임은 연결된 컨트롤러를 자동으로 감지하고 그에 따라 입력 프롬프트를 전환합니다 — Xbox 컨트롤러는 Xbox 버튼 아이콘을 표시하고, PlayStation 컨트롤러는 PlayStation 아이콘을 표시합니다.

### 기본 버튼 배치 (Xbox 컨트롤러)

| 액션 | 버튼 |
|--------|--------|
| 약공격 | X |
| 강공격 / 스킬 | Y |
| 태그 스위치 (영웅 2) | LB |
| 태그 스위치 (영웅 3) | RB |
| 회피 | B |
| 상호작용 / 확인 | A |
| 스킬 1 | RT |
| 스킬 2 | LT |
| 프로스트 게이지 버스트 | RT + LT (동시) |
| 메뉴 / 일시정지 | Start |
| 영웅 선택 | Back |

기본 배치는 기능적이지만 태그 콤보 시스템에 최적화되어 있지는 않습니다. 어깨 버튼(LB/RB)에 있는 태그 스위치 배치는 전투 중 오른쪽 스틱에서 엄지를 떼지 않고도 태그 전환이 가능해야 하기 때문에 논리적입니다. 그러나 B에 있는 회피 배치는 콤보 실행 중 회피를 위해 면 버튼에서 엄지를 움직여야 하며, 이로 인해 타이밍 갭이 발생합니다. 이 갭은 컨트롤러 플레이어의 콤보가 끊어지는 가장 흔한 원인입니다.

### 기본 버튼 배치 (PlayStation 컨트롤러)

PlayStation 배치는 해당하는 PlayStation 버튼(Square, Triangle, L1, R1, Circle, Cross, R2, L2)으로 Xbox 배치를 그대로 반영합니다. Circle에 있는 회피 타이밍 이슈도 동일하게 적용됩니다. 이 가이드의 추천 사항은 두 컨트롤러 유형 모두에 적용되며, 두 컨트롤러에 대한 버튼 참조가 제공됩니다.

## 태그 콤보를 위한 추천 컨트롤러 배치

다음 배치는 DragonSword: Awakening의 태그 콤보 시스템에 특별히 최적화되어 있습니다. 빠른 태그 전환, 부드러운 회피 통합, 전투 시퀀스 중 최소한의 엄지 움직임에 우선순위를 둡니다.

### 최적화된 버튼 배치 (Xbox)

| 액션 | 버튼 | 이유 |
|--------|--------|--------|
| 약공격 | X | 표준 위치, 고빈도 액션 |
| 강공격 / 스킬 | Y | 표준 위치, 덜 자주 사용됨 |
| 태그 스위치 (영웅 2) | LB | 어깨 버튼으로 엄지 움직임 없이 전투 중 태그 가능 |
| 태그 스위치 (영웅 3) | RB | 위와 동일 |
| 회피 | 오른쪽 스틱 클릭 (R3) | 회피 중에도 엄지를 스틱에 유지 — 움직임 갭 없음 |
| 상호작용 / 확인 | A | 표준 위치 |
| 스킬 1 | RT | 반복 사용에 편안한 트리거 |
| 스킬 2 | LT | 반복 사용에 편안한 트리거 |
| 프로스트 게이지 버스트 | RT + LT | 동시 트리거 누름, 활성화 능력에 직관적 |
| 태그 선택 (영웅 1) | Back | 사이클링 없이 주 영웅으로 복귀 가능 |
| 메뉴 / 일시정지 | Start | 표준 위치 |

핵심적인 변경 사항은 회피를 B에서 R3(오른쪽 스틱 클릭)로 옮긴 것입니다. 이를 통해 카메라 제어를 위해 오른쪽 스틱에 엄지를 유지하면서 회피할 수 있어, 콤보가 끊어지는 원인이 되는 타이밍 갭을 제거합니다. 이 배치에 익숙해지는 데는 약 2~3시간의 연습이 필요하지만, 일단 적응하면 태그 콤보 실행이 훨씬 부드러워진다는 것을 알 수 있습니다.

### 최적화된 버튼 배치 (PlayStation)

| 액션 | 버튼 |
|--------|--------|
| 약공격 | Square |
| 강공격 / 스킬 | Triangle |
| 태그 스위치 (영웅 2) | L1 |
| 태그 스위치 (영웅 3) | R1 |
| 회피 | R3 |
| 상호작용 / 확인 | Cross |
| 스킬 1 | R2 |
| 스킬 2 | L2 |
| 프로스트 게이지 버스트 | R2 + L2 |
| 태그 선택 (영웅 1) | Select |
| 메뉴 / 일시정지 | Start |

## Steam Input 구성

Steam Input은 인게임 설정에서 제공하는 것 이상의 컨트롤러 매핑을 사용자 정의할 수 있는 강력한 도구입니다. DragonSword: Awakening용 Steam Input 구성에 접근하려면:

1. Steam을 열고 라이브러리로 이동합니다.

2. DragonSword: Awakening을 우클릭하고 "속성"을 선택합니다.

3. "컨트롤러" 탭으로 이동합니다.

4. "게임 컨트롤러 구성 관리"를 클릭합니다.

5. "구성 찾아보기"를 선택하여 커뮤니티에서 만든 레이아웃을 찾거나 직접 만듭니다.

### 커뮤니티 구성

여러 커뮤니티 멤버가 DragonSword: Awakening용 최적화된 컨트롤러 구성을 공유했습니다. 최상의 결과를 위해 "tag combo" 또는 "competitive" 태그가 붙은 구성을 검색하세요. 출시 시점 기준으로 가장 인기 있는 커뮤니티 구성은 "DSA Tag Combo Pro"이며, 이는 위에서 설명한 R3 회피 배치와 함께 패들 컨트롤러를 위한 추가 조정을 구현합니다.

### Elite/Pro 컨트롤러용 커스텀 구성

Xbox Elite Series 2, DualSense Edge 또는 후면 패들이 있는 다른 컨트롤러를 사용하는 경우, 후면 패들을 추가 태그 기능에 할당하세요. 추천되는 패들 매핑은 다음과 같습니다:

- **왼쪽 패들**: 태그 스위치 (영웅 1) — 주 영웅으로 즉시 복귀 가능

- **오른쪽 패들**: 회피 — 면 버튼 회피를 선호하는 경우 R3 회피의 대안

후면 패들은 손가락을 기본 위치에서 움직일 필요가 없어 태그 콤보 실행을 가능한 한 부드럽게 만듭니다. 경쟁 수준의 플레이에 진심이라면, 후면 패들이 있는 컨트롤러는 가치가 있는 투자입니다.

## 컨트롤러 vs 키보드와 마우스: 어느 것이 더 나은가?

이 질문은 DragonSword: Awakening 커뮤니티에서 자주 나옵니다. 정직한 답변은 두 입력 방식 모두 viable하며, 최선의 선택은 개인 취향과 경험에 따라 다르다는 것입니다.

### 컨트롤러의 장점

- **인체공학적 편안함**: 컨트롤러는 장시간 플레이 세션에 더 편안하여 손과 손목의 피로를 줄여줍니다.

- **아날로그 이동**: 왼쪽 스틱은 가변 속도로 360도 이동을 제공하여 오픈 월드 탐험과 전투 중 정확한 위치 선정에 유용합니다.

- **어깨 버튼 접근성**: 어깨 버튼의 태그 전환은 자연스럽고 빠르며 느껴집니다.

- **진동 피드백**: 시그널 스킬 발동과 프로스트 게이지 충전 중의 햅틱 피드백은 유용한 타이밍 단서를 제공합니다.

### 키보드와 마우스의 장점

- **정밀한 카메라 제어**: 마우스 룩은 오른쪽 스틱 카메라 제어보다 빠르고 정밀하여 태그 콤보 중 빠르게 움직이는 적을 추적하는 데 중요합니다.

- **더 많은 키 바인드**: 키보드는 더 많은 키에 접근할 수 있어, 수정자 키에 의존하지 않고 각 영웅의 스킬에 전용 바인드를 할당할 수 있습니다.

- **엄지 움직임 갭 없음**: 키보드 회피(일반적으로 스페이스바)는 전투 키에서 손을 움직일 필요가 없습니다.

- **더 높은 프레임률 잠재력**: 일부 하드웨어 구성에서 Steam Input 변환을 통한 컨트롤러 입력보다 키보드 입력의 지연 시간이 더 낮습니다.

### 추천

대부분의 플레이어에게 DragonSword: Awakening에서는 컨트롤러가 더 나은 선택입니다. 태그 콤보 시스템은 어깨 버튼 전환을 중심으로 설계되었으며 진동 피드백이 실질적인 게임플레이 가치를 제공하기 때문입니다. PC 액션 게임 배경에서 왔고 마우스 룩 카메라 제어를 선호한다면 키보드와 마우스가 더 좋습니다. 두 입력 모두 최고 수준에서 경쟁력이 있습니다 — 제한 요소는 입력 방식이 아니라 플레이어의 실력입니다.

## 일반적인 컨트롤러 문제 해결

### 컨트롤러가 감지되지 않음

DragonSword: Awakening에서 컨트롤러가 감지되지 않으면, 먼저 Steam이 컨트롤러를 감지하는지 확인하세요. Steam > 설정 > 컨트롤러 > 일반 컨트롤러 설정을 열고 컨트롤러 유형이 체크되어 있는지 확인하세요. Steam이 컨트롤러를 감지하지만 게임이 감지하지 못하는 경우, 게임의 속성 > 컨트롤러 탭에서 Steam Input을 비활성화하고 다시 활성화해 보세요.

### 입력 지연

컨트롤러의 입력 지연은 일반적으로 Steam Input 처리 오버헤드로 인해 발생합니다. 눈에 띄는 입력 지연(약 15ms 이상)을 경험하면, 게임의 컨트롤러 설정에서 Steam Input에서 "네이티브" 입력 모드로 전환해 보세요. 네이티브 모드는 Steam의 변환 레이어를 우회하지만 모든 컨트롤러 유형을 지원하지는 않을 수 있습니다. 유선 컨트롤러의 경우 Bluetooth 대신 USB 연결을 사용하면 입력 지연이 약 5~10ms 감소합니다.

### 버튼 프롬프트가 잘못된 컨트롤러 유형을 표시함

PlayStation 컨트롤러를 사용 중인데 게임이 Xbox 프롬프트를 표시하거나(또는 그 반대의 경우), 인게임 옵션 메뉴에서 "컨트롤러 유형" 설정을 토글하세요. DragonSword: Awakening은 연결된 컨트롤러에 관계없이 표시할 프롬프트 스타일을 수동으로 선택할 수 있습니다.

## 자주 묻는 질문

### DragonSword Awakening이 DualSense 적응형 트리거를 지원하나요?

출시 시점을 기준으로 DragonSword: Awakening은 기본적인 DualSense 기능(버튼, 스틱, 자이로)을 지원하지만 DualSense 컨트롤러의 적응형 트리거 기능은 활용하지 않습니다. 트리거는 저항 피드백 없이 표준 아날로그 트리거로 작동합니다. Hound13은 향후 업데이트에서 적응형 트리거 지원을 추가할 수 있으며, 이는 프로스트 게이지 충전과 스킬 활성화 중 저항 피드백을 제공할 것입니다.

### Nintendo Switch Pro 컨트롤러를 사용할 수 있나요?

예, Switch Pro 컨트롤러는 Steam Input을 통해 작동합니다. 버튼 배치는 Xbox 배치와 유사합니다(A/B/X/Y 위치가 Xbox와 비교해 뒤바뀌어 있지만 Steam Input이 매핑을 자동으로 처리합니다). Switch Pro 컨트롤러는 Steam Input을 통해 DragonSword: Awakening에서 진동을 지원하지 않습니다. 기본적인 게임플레이에는 잘 작동하지만, 경쟁 플레이어는 더 많은 기능을 갖춘 컨트롤러를 선호할 수 있습니다.

### 자이로 조준이 지원되나요?

DragonSword: Awakening은 출시 시점을 기준으로 자이로 보조 조준을 지원하지 않습니다. PlayStation DualSense 및 Switch Pro 컨트롤러의 자이로 센서는 게임에서 활용되지 않습니다. 자이로 컨트롤을 선호하는 경우 Steam Input의 "자이로 → 마우스" 모드를 활성화할 수 있지만, 이는 타인칭 액션 RPG에 최적이라고 느껴지지 않을 수 있는 우회 방법입니다.

### 게임 중간에 컨트롤러와 키보드 간에 어떻게 전환하나요?

DragonSword: Awakening은 마지막으로 입력을 받은 장치에 따라 자동으로 입력을 전환합니다. 컨트롤러를 들고 버튼을 누르면 게임이 컨트롤러 모드로 전환됩니다. 키보드에서 키를 누르면 다시 전환됩니다. 이 핫스왑ping은 대부분의 경우 원활하게 작동하지만, 전환 중 UI 프롬프트가 잠시 깜빡일 수 있습니다. 입력 옵션에 대한 자세한 내용은 [시스템 요구사항 가이드](/en/system-requirements/system-requirements/)를 참조하세요.

### 프로 DragonSword Awakening 플레이어들은 어떤 컨트롤러를 사용하나요?

게임이 이제 막 출시되었기 때문에 경쟁 씬은 아직 형성 중입니다. 초기 커뮤니티 리더들은 후면 패들 이점을 위해 Xbox Elite Series 2 컨트롤러를 사용하거나 인체공학적 디자인을 위해 표준 DualSense 컨트롤러를 사용하는 경향이 있습니다. 가장 중요한 요소는 특정 컨트롤러 모델이 아니라 버튼 배치 구성입니다 — 이 가이드에서 설명한 R3 회피 배치는 경쟁 태그 콤보 실행의 커뮤니티 표준이 되어가고 있습니다. 전투 팁에 대한 자세한 내용은 [전투 시스템 가이드](/en/guides/combat-system-guide/)를 참조하세요.
