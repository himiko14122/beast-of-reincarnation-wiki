DragonSword: Awakening は、一瞬のタイミングがコンボチェーンの成否を分けるタッグアクションRPGです。タッグ戦闘システムでは、3人の英雄を素早く切り替え、シグナルスキルを発動し、正確なタイミングでスイッチングシグナルを実行する必要があります。これら全てを敵の攻撃を回避し、フロストゲージを管理しながら行います。多くのプレイヤーにとって、コントローラーは人間工学に基づいた快適さとマッスルメモリーの利点を提供し、この要求の厳しいゲームプレイをより扱いやすくします。このガイドでは、DragonSword: Awakening のコントローラーサポートについて、基本設定から競技レベルのタッグコンボ実行のための高度な設定まで、知っておくべき全てを網羅します。

本作はSteam入力を通じて、Xbox、PlayStation、および様々なサードパーティ製コントローラーにネイティブ対応しています。Xboxコントローラーの非対称スティック配置を好むか、PlayStationコントローラーの対称配置を好むかに関わらず、DragonSword: Awakening は両方で動作します。重要なのは、一般的なアクションゲーム用に設計されたデフォルト設定ではなく、タッグ戦闘特有の要求に合わせてボタンレイアウトを最適化することです。

## ネイティブコントローラーサポート：すぐに使える機能

DragonSword: Awakening は、最も一般的なコントローラータイプに対してデフォルトのボタンマッピングを備えたネイティブコントローラーサポートを提供します。ゲームは接続されたコントローラーを自動的に検出し、それに応じて入力プロンプトを切り替えます。XboxコントローラーはXboxのボタンアイコンを表示し、PlayStationコントローラーはPlayStationのアイコンを表示します。

### デフォルトボタンレイアウト (Xbox コントローラー)

| アクション | ボタン |
|--------|--------|
| 弱攻撃 | X |
| 強攻撃 / スキル | Y |
| タッグ切替 (英雄2) | LB |
| タッグ切替 (英雄3) | RB |
| 回避 | B |
| インタラクト / 決定 | A |
| スキル1 | RT |
| スキル2 | LT |
| フロストゲージバースト | RT + LT (同時押し) |
| メニュー / ポーズ | Start |
| 英雄選択 | Back |

デフォルトレイアウトは機能的ですが、タッグコンボシステムには最適化されていません。タッグ切替がショルダーボタン（LB/RB）に配置されているのは、戦闘中に右スティックから親指を離さずにタッグ切替を行う必要があるため理にかなっています。しかし、回避がBボタンに配置されているため、回避するために親指をフェイスボタンから移動させる必要があり、コンボ実行中にタイムラグが生じます。このタイムラグは、コントローラープレイヤーがコンボを失敗する最も一般的な原因です。

### デフォルトボタンレイアウト (PlayStation コントローラー)

PlayStationのレイアウトは、対応するPlayStationボタン（□、△、L1、R1、○、×、R2、L2）でXboxレイアウトを反映しています。○ボタンでの回避に関する同じタイミング問題が当てはまります。このガイドの推奨事項は両方のコントローラータイプに適用され、ボタンの参照は両方に対して提供されます。

## タッグコンボに推奨するコントローラーレイアウト

以下のレイアウトは、DragonSword: Awakening のタッグコンボシステムに特化して最適化されています。迅速なタッグ切替、スムーズな回避の統合、戦闘中の親指の動きを最小限に抑えることを優先しています。

### 最適化されたボタンレイアウト (Xbox)

| アクション | ボタン | 理由 |
|--------|--------|--------|
| 弱攻撃 | X | 標準的な位置、高頻度のアクション |
| 強攻撃 / スキル | Y | 標準的な位置、使用頻度は低い |
| タッグ切替 (英雄2) | LB | ショルダーボタンにより、親指を動かさずに戦闘中にタッグ切替が可能 |
| タッグ切替 (英雄3) | RB | 同上 |
| 回避 | 右スティック押込 (R3) | 回避中も親指をスティックに置いたままにできる — 動作のギャップなし |
| インタラクト / 決定 | A | 標準的な位置 |
| スキル1 | RT | 快適な繰り返し使用のためのトリガー |
| スキル2 | LT | 快適な繰り返し使用のためのトリガー |
| フロストゲージバースト | RT + LT | トリガー同時押し、アクティベート能力に直感的 |
| タッグ選択 (英雄1) | Back | サイクリングせずにメインの英雄に戻れる |
| メニュー / ポーズ | Start | 標準的な位置 |

重要な変更点は、回避をBからR3（右スティック押込）に移動することです。これにより、カメラ操作のために右スティックに親指を置いたまま回避できるため、コンボ失敗の原因となるタイムラグを排除できます。このレイアウトに慣れるには約2〜3時間の練習が必要ですが、一度適応すれば、タッグコンボの実行が大幅にスムーズになることがわかるでしょう。

### 最適化されたボタンレイアウト (PlayStation)

| アクション | ボタン |
|--------|--------|
| 弱攻撃 | □ |
| 強攻撃 / スキル | △ |
| タッグ切替 (英雄2) | L1 |
| タッグ切替 (英雄3) | R1 |
| 回避 | R3 |
| インタラクト / 決定 | × |
| スキル1 | R2 |
| スキル2 | L2 |
| フロストゲージバースト | R2 + L2 |
| タッグ選択 (英雄1) | Select |
| メニュー / ポーズ | Start |

## Steam入力の設定

Steam入力は、ゲーム内設定が提供する以上のコントローラーマッピングのカスタマイズを可能にする強力なツールです。DragonSword: Awakening のSteam入力設定にアクセスするには：

1. Steamを開き、ライブラリに移動します。
2. DragonSword: Awakening を右クリックし、「プロパティ」を選択します。
3. 「コントローラー」タブに移動します。
4. 「ゲームコントローラー設定を管理」をクリックします。
5. 「コンフィグを参照」を選択してコミュニティ作成のレイアウトを見つけるか、独自のレイアウトを作成します。

### コミュニティ設定

複数のコミュニティメンバーがDragonSword: Awakening 向けに最適化されたコントローラー設定を共有しています。最良の結果を得るには、「タッグコンボ」または「競技」とタグ付けされた設定を検索してください。発売時点で最も人気のあるコミュニティ設定は「DSA Tag Combo Pro」で、上記のR3回避レイアウトに加えて、パドル付きコントローラー向けの追加調整が実装されています。

### Elite/Proコントローラー向けカスタム設定

Xbox Elite シリーズ 2、DualSense Edge、または背面パドル付きのその他のコントローラーを使用している場合は、背面パドルに追加のタグ機能を割り当ててください。推奨されるパドルマッピングは次のとおりです：

- **左パドル**: タッグ切替 (英雄1) — メインの英雄に即座に戻ることができます
- **右パドル**: 回避 — フェイスボタン回避を好む場合のR3回避の代替

背面パドルは、デフォルトの位置から指を動かす必要をなくし、タッグコンボの実行を可能な限りスムーズにします。競技レベルのプレイに真剣に取り組むなら、背面パドル付きコントローラーは投資する価値があります。

## コントローラー vs キーボードとマウス：どちらが優れているか？

この質問はDragonSword: Awakening コミュニティで頻繁に提起されます。正直な答えは、両方の入力方法が実行可能であり、最適な選択は個人の好みと経験に依存するということです。

### コントローラーの利点

- **人間工学に基づいた快適さ**: コントローラーは長時間のプレイセッションでより快適であり、手や手首の疲労を軽減します。
- **アナログ移動**: 左スティックは可変速度での360度の移動を提供し、オープンワールド探索や戦闘中の正確な位置取りに役立ちます。
- **ショルダーボタンのアクセシビリティ**: ショルダーボタンでのタッグ切替は自然で迅速に感じられます。
- **振動フィードバック**: シグナルスキル発動時やフロストゲージチャージ時の触覚フィードバックは、有用なタイミングの合図を提供します。

### キーボードとマウスの利点

- **正確なカメラ操作**: マウスルックは右スティックのカメラ操作よりも高速かつ正確であり、タッグコンボ中に高速移動する敵を追跡するのに重要です。
- **より多くのキーバインド**: キーボードはより多くのキーにアクセスでき、修飾キーに頼らずに各英雄のスキルに専用のキーを割り当てることができます。
- **親指の移動ギャップなし**: キーボードの回避（通常はスペースバー）は、戦闘キーから手を動かす必要がありません。
- **より高いフレームレートの可能性**: 一部のハードウェア構成では、Steam入力変換を介したコントローラー入力よりもキーボード入力の方が低遅延です。

### 推奨

ほとんどのプレイヤーにとって、DragonSword: Awakening ではコントローラーがより良い選択です。なぜなら、タッグコンボシステムはショルダーボタン切替を中心に設計されており、振動フィードバックが真のゲームプレイ価値を提供するからです。PCアクションゲームのバックグラウンドを持ち、マウスルックのカメラ操作を好む場合は、キーボードとマウスが好ましいです。最高レベルでは両方の入力が競合的であり、制限要因は入力方法ではなくプレイヤーのスキルです。

## 一般的なコントローラー問題のトラブルシューティング

### コントローラーが検出されない

DragonSword: Awakening がコントローラーを検出しない場合は、まずSteamがそれを検出していることを確認してください。Steam > 設定 > コントローラー > 一般コントローラー設定を開き、コントローラータイプがチェックされていることを確認します。Steamがコントローラーを検出しているのにゲームが検出しない場合は、ゲームのプロパティ > コントローラータブでSteam入力を無効にしてから再度有効にしてみてください。

### 入力遅延

コントローラーの入力遅延は、通常、Steam入力処理のオーバーヘッドによって引き起こされます。顕著な入力遅延（約15ms以上）を感じる場合は、ゲームのコントローラー設定でSteam入力から「ネイティブ」入力モードに切り替えてみてください。ネイティブモードはSteamの変換レイヤーをバイパスしますが、すべてのコントローラータイプをサポートしていない場合があります。有線コントローラーの場合、Bluetoothの代わりにUSB接続を使用すると、入力遅延が約5〜10ms減少します。

### ボタンプロンプトが間違ったコントローラータイプを表示する

PlayStationコントローラーを使用しているのにゲームがXboxのプロンプトを表示する場合（またはその逆）、ゲーム内オプションメニューで「コントローラータイプ」設定を切り替えてください。DragonSword: Awakening では、接続されているコントローラーに関係なく、表示するプロンプトスタイルを手動で選択できます。

## よくある質問

### DragonSword Awakening はDualSenseのアダプティブトリガーに対応していますか？

発売時点では、DragonSword: Awakening は基本的なDualSense機能（ボタン、スティック、ジャイロ）をサポートしていますが、DualSenseコントローラーのアダプティブトリガー機能は利用していません。トリガーは抵抗フィードバックなしで標準のアナログトリガーとして機能します。Hound13は将来のアップデートでアダプティブトリガーサポートを追加する可能性があり、フロストゲージのチャージやスキル発動時に抵抗フィードバックが提供されるようになるでしょう。

### Nintendo Switch Proコントローラーを使用できますか？

はい、Switch ProコントローラーはSteam入力を通じて動作します。ボタンレイアウトはXboxレイアウトと似ています（A/B/X/Yの位置はXboxと入れ替わっていますが、Steam入力が自動的にマッピングを処理します）。Switch Proコントローラーは、Steam入力を通じたDragonSword: Awakening では振動をサポートしていません。基本的なゲームプレイには十分ですが、競技プレイヤーはより多くの機能を備えたコントローラーを好むかもしれません。

### ジャイロエイミングはサポートされていますか？

DragonSword: Awakening は発売時点でジャイロアシストエイミングをサポートしていません。PlayStation DualSenseおよびSwitch Proコントローラーのジャイロセンサーはゲームで利用されていません。ジャイロコントロールを希望する場合は、Steam入力の「Gyro to Mouse」モードを有効にすることができますが、これはサードパーソンアクションRPGには最適に感じられないかもしれない回避策です。

### ゲーム途中でコントローラーとキーボードを切り替えるにはどうすればよいですか？

DragonSword: Awakening は、最後に入力を受け取ったデバイスに基づいて自動的に入力を切り替えます。コントローラーを手に取りボタンを押すと、ゲームはコントローラーモードに切り替わります。キーボードのキーを押すと、キーボードモードに戻ります。このホットスワップはほとんどの場合シームレスに機能しますが、移行中にUIプロンプトが一瞬ちらつくことがあります。入力オプションの詳細については、[システム要件ガイド](/ja/system-requirements/system-requirements/)をご覧ください。

### DragonSword Awakening のプロプレイヤーはどのコントローラーを使用していますか？

ゲームが発売されたばかりであるため、競技シーンはまだ形成中です。初期のコミュニティリーダーは、背面パドルの利点のためにXbox Elite シリーズ 2コントローラーを使用するか、人間工学に基づいたデザインのために標準のDualSenseコントローラーを使用する傾向があります。最も重要な要素は特定のコントローラーモデルではなく、ボタンレイアウトの設定です。このガイドで説明されているR3回避レイアウトは、競技タッグコンボ実行のためのコミュニティ標準になりつつあります。戦闘のヒントについては、[戦闘システムガイド](/ja/guides/combat-system-guide/)をご覧ください。
