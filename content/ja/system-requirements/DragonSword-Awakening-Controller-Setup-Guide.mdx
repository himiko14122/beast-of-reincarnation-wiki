DragonSword: AwakeningはタグチームアクションRPGであり、一瞬の判断でコンボチェーンが決まるかどうかが決まります。タグ戦闘システムでは、3人のヒーロー間を高速で切り替え、シグナルスキルを発動し、正確なタイミングウィンドウ内でスイッチングシグナルを実行する必要があります——同時に敵の攻撃を避け、フロストゲージを管理することも求められます。多くのプレイヤーにとって、コントローラーはこの要求の厳しいゲームプレイをより扱いやすくするエルゴノミックな快適さと筋肉記憶の利点を提供します。このガイドでは、基本的なセットアップから競技レベルのタグコンボ実行のための高度な構成まで、DragonSword: Awakeningにおけるコントローラーサポートについて知っておくべきすべてをカバーします。

このゲームはSteam Inputを通じてXbox、PlayStation、およびさまざまなサードパーティ製コントローラーに対応しています。Xboxコントローラーの非対称スティックレイアウトを好むか、PlayStationコントローラーの対称レイアウトを好むかにかかわらず、DragonSword: Awakeningは両方に対応しています。鍵となるのは、一般的なアクションゲーム向けに設計されたデフォルト設定ではなく、タグチーム戦闘の特定の要求に合わせてボタンレイアウトを構成することです。

## ネイティブコントローラーサポート：初期状態で動作するもの

DragonSword: Awakeningは、最も一般的なコントローラータイプに対してデフォルトのボタンマッピングを備えたネイティブコントローラーサポートを提供します。ゲームは接続されたコントローラーを自動的に検出し、入力プロンプトをそれに応じて切り替えます——XboxコントローラーはXboxボタンアイコンを、PlayStationコントローラーはPlayStationアイコンを表示します。

### デフォルトボタンレイアウト（Xboxコントローラー）

| アクション | ボタン |
|--------|--------|
| 弱攻撃 | X |
| 強攻撃 / スキル | Y |
| タグスイッチ（ヒーロー2） | LB |
| タグスイッチ（ヒーロー3） | RB |
| 回避 | B |
| インタラクト / 確認 | A |
| スキル1 | RT |
| スキル2 | LT |
| フロストゲージバースト | RT + LT（同時押し） |
| メニュー / 一時停止 | Start |
| ヒーロー選択 | Back |

デフォルトレイアウトは機能的ですが、タグコンボシステムには最適化されていません。タグスイッチがショルダーボタン（LB/RB）に配置されているのは、戦闘中に右スティックから親指を離さずにタグ切り替えを行う必要があるため、理にかなっています。しかし、回避がBボタンに配置されているため、回避時に顔ボタンから親指を移動する必要があり、コンボ実行中にタイミングのギャップが発生します。このギャップが、コントローラープレイヤーにとってコンボが途切れる最も一般的な原因です。

### デフォルトボタンレイアウト（PlayStationコントローラー）

PlayStationレイアウトは、対応するPlayStationボタン（Square、Triangle、L1、R1、Circle、Cross、R2、L2）を使用してXboxレイアウトを反映しています。Circleボタンでの回避のタイミングの問題も同様に存在します。このガイドでの推奨事項は両方のコントローラータイプに適用され、両方のボタン参照が提供されます。

## タグコンボに最適なコントローラーレイアウト

以下のレイアウトは、DragonSword: Awakeningのタグコンボシステム専用に最適化されています。高速なタグ切り替え、スムーズな回避統合、戦闘シーケンス中の親指の動きの最小化に重点を置いています。

### 最適化されたボタンレイアウト（Xbox）

| アクション | ボタン | 理由 |
|--------|--------|-------|
| 弱攻撃 | X | 標準的な位置、頻度の高いアクション |
| 強攻撃 / スキル | Y | 標準的な位置、使用頻度は低い |
| タグスイッチ（ヒーロー2） | LB | ショルダーボタンは親指を動かさずに戦闘中にタグ切り替え可能 |
| タグスイッチ（ヒーロー3） | RB | 上記と同じ |
| 回避 | 右スティッククリック（R3） | 回避中に親指をスティック上に保持——動きのギャップなし |
| インタラクト / 確認 | A | 標準的な位置 |
| スキル1 | RT | 繰り返し使用に快適なトリガー |
| スキル2 | LT | 繰り返し使用に快適なトリガー |
| フロストゲージバースト | RT + LT | 同時トリガープッシュ、アクティブ化能力に直感的 |
| タグ選択（ヒーロー1） | Back | サイクルせずにプライマリヒーローに戻れる |
| メニュー / 一時停止 | Start | 標準的な位置 |

重要な変更は、回避をBボタンからR3（右スティッククリック）に移動することです。これにより、カメラ制御のために右スティック上に親指を保持しながら回避できるようになり、コンボが途切れる原因となるタイミングのギャップを排除します。このレイアウトに慣れるには約2〜3時間の練習が必要ですが、適応すればタグコンボの実行が大幅にスムーズになることがわかります。

### 最適化されたボタンレイアウト（PlayStation）

| アクション | ボタン |
|--------|--------|
| 弱攻撃 | Square |
| 強攻撃 / スキル | Triangle |
| タグスイッチ（ヒーロー2） | L1 |
| タグスイッチ（ヒーロー3） | R1 |
| 回避 | R3 |
| インタラクト / 確認 | Cross |
| スキル1 | R2 |
| スキル2 | L2 |
| フロストゲージバースト | R2 + L2 |
| タグ選択（ヒーロー1） | Select |
| メニュー / 一時停止 | Start |

## Steam Input構成

Steam Inputは、ゲーム内設定が提供する範囲を超えてコントローラーマッピングをカスタマイズできる強力なツールです。DragonSword: AwakeningのSteam Input構成にアクセスするには：

1. Steamを開き、ライブラリに移動します。

2. DragonSword: Awakeningを右クリックし、「プロパティ」を選択します。

3. 「コントローラー」タブに移動します。

4. 「ゲーム別コントローラーの設定を管理」をクリックします。

5. 「コミュニティ構成を閲覧」を選択してコミュニティが作成したレイアウトを探すか、自分の構成を作成します。

### コミュニティ構成

複数のコミュニティメンバーがDragonSword: Awakening用の最適化されたコントローラー構成を共有しています。「tag combo」または「competitive」のタグが付いた構成を検索すると、最良の結果が得られます。リリース時点での最も人気のあるコミュニティ構成は「DSA Tag Combo Pro」であり、上記のR3回避レイアウトをパドルコントローラー向けの追加調整とともに実装しています。

### Elite/Proコントローラー向けのカスタム構成

Xbox Elite Series 2、DualSense Edge、またはリアパドル付きのその他のコントローラーを使用している場合は、リアパドルを追加のタグ機能に割り当ててください。推奨されるパドルマッピングは以下の通りです：

- **左パドル**：タグスイッチ（ヒーロー1）——プライマリヒーローに即座に戻れる

- **右パドル**：回避——顔ボタンでの回避を好む場合のR3回避の代替

リアパドルはすべての指をデフォルト位置から動かす必要をなくし、タグコンボの実行を可能な限りスムーズにします。競技レベルのプレイに真剣に取り組む場合、リアパドル付きコントローラーは価値のある投資です。

## コントローラー vs キーボードとマウス：どちらが優れているか？

この質問はDragonSword: Awakeningコミュニティで頻繁に出てきます。正直な答えは、両方の入力方法が実行可能であり、最良の選択はあなたの個人的な好みと経験に依存するということです。

### コントローラーの利点

- **エルゴノミックな快適さ**：コントローラーは長時間のプレイセッションでより快適であり、手と手首の疲労を軽減します。

- **アナログ移動**：左スティックは可変速度で360度の移動を提供し、オープンワールド探索と戦闘中の正確なポジショニングに役立ちます。

- **ショルダーボタンのアクセシビリティ**：ショルダーボタンでのタグ切り替えは自然で迅速に感じます。

- **振動フィードバック**：シグナルスキル発動時とフロストゲージチャージ時の触覚フィードバックは便利なタイミングキューを提供します。

### キーボードとマウスの利点

- **正確なカメラ制御**：マウス視点は右スティックカメラ制御よりも高速かつ正確であり、タグコンボ中の高速移動する敵を追跡するために重要です。

- **より多くのキーバインド**：キーボードはより多くのキーにアクセスでき、修飾キーに頼ることなく各ヒーローのスキルに専用のバインドを割り当てられます。

- **親指の動きのギャップなし**：キーボードでの回避（通常はスペースキー）は戦闘用キーから手を移動する必要がありません。

- **より高いフレームレート潜在能力**：一部のハードウェア構成では、Steam Input変換を介したコントローラー入力よりもキーボード入力の方がレイテンシが低い。

### 推奨事項

ほとんどのプレイヤーにとって、タグコンボシステムがショルダーボタン切り替えを中心に設計されており、振動フィードバックが実際のゲームプレイ価値を提供するため、コントローラーがDragonSword: Awakeningのより良い選択です。PCアクションゲームの背景を持ち、マウス視点カメラ制御を好む場合は、キーボードとマウスが好ましいです。最高レベルの両方の入力は競争力があります——制限要因は入力方法ではなくプレイヤースキルです。

## 一般的なコントローラー問題のトラブルシューティング

### コントローラーが検出されない

DragonSword: Awakeningでコントローラーが検出されない場合、まずSteamがそれを検出していることを確認してください。Steam > 設定 > コントローラー > 全般コントローラー設定を開き、コントローラータイプがチェックされていることを確認します。Steamがコントローラーを検出しているがゲームが検出していない場合は、ゲームのプロパティ > コントローラータブでSteam Inputを無効にしてから再度有効にしてみてください。

### 入力ラグ

コントローラーの入力ラグは通常、Steam Inputの処理オーバーヘッドが原因です。顕著な入力遅延（約15ms以上）を感じる場合は、ゲームのコントローラー設定でSteam Inputから「ネイティブ」入力モードへの切り替えを試してください。ネイティブモードはSteamの変換層をバイパスしますが、すべてのコントローラータイプをサポートしない場合があります。有線コントローラーの場合、Bluetoothの代わりにUSB接続を使用することで入力ラグが約5〜10ms削減されます。

### ボタンプロンプトが間違ったコントローラータイプを表示する

PlayStationコントローラーを使用しているのにゲームがXboxプロンプトを表示する場合（またはその逆）、ゲーム内オプションメニューの「コントローラータイプ」設定を切り替えてください。DragonSword: Awakeningでは、接続されているコントローラーに関係なく表示するプロンプトスタイルを手動で選択できます。

## FAQ

### DragonSword AwakeningはDualSenseのアダプティブトリガーに対応していますか？

リリース時点で、DragonSword: Awakeningは基本的なDualSense機能（ボタン、スティック、ジャイロ）に対応していますが、DualSenseのアダプティブトリガー機能は活用していません。トリガーは抵抗フィードバックなしの標準のアナログトリガーとして機能します。Hound13は将来のアップデートでアダプティブトリガーサポートを追加する可能性があり、これによりフロストゲージチャージとスキル発動時に抵抗フィードバックが提供されます。

### Nintendo Switch Proコントローラーは使用できますか？

はい、Switch Pro ControllerはSteam Inputを介して動作します。ボタンレイアウトはXboxレイアウトと似ています（A/B/X/Yの位置はXboxと比較して入れ替わっていますが、Steam Inputがマッピングを自動的に処理します）。Switch Pro ControllerはSteam Inputを介したDragonSword: Awakeningでは振動をサポートしていません。基本ゲームプレイには十分機能しますが、競技プレイヤーはより多くの機能を備えたコントローラーを好む場合があります。

### ジャイロエイミングはサポートされていますか？

DragonSword: Awakeningはリリース時点でジャイロ支援エイミングをサポートしていません。PlayStation DualSenseとSwitch Pro Controllerのジャイロセンサーはゲームで活用されていません。ジャイロコントロールを好む場合は、Steam Inputの「ジャイロからマウス」モードを有効にできますが、これはサードパーソンアクションRPGには最適に感じられない可能性がある回避策です。

### ゲーム中にコントローラーとキーボードを切り替えるにはどうすればよいですか？

DragonSword: Awakeningは最後に入力を受信したデバイスに基づいて自動的に入力を切り替えます。コントローラーを手に取ってボタンを押すと、ゲームはコントローラーモードに切り替わります。キーボードのキーを押すと、キーボードに戻ります。このホットスワップはほとんどの場合シームレスに動作しますが、移行中にUIプロンプトが一瞬ちらつく場合があります。入力オプションの詳細については、[システム要件ガイド](/en/system-requirements/system-requirements/)を参照してください。

### プロDragonSword Awakeningプレイヤーはどのコントローラーを使用していますか？

ゲームがまだリリースされたばかりであるため、競技シーンはまだ形成中です。アーリーコミュニティリーダーは、リアパドルの利点のためにXbox Elite Series 2コントローラーを使用するか、人間工学に基づいたデザインのために標準のDualSenseコントローラーを使用する傾向があります。最も重要な要素は特定のコントローラーモデルではなく、ボタンレイアウト構成です——このガイドで説明したR3回避レイアウトが、競技タグコンボ実行のためのコミュニティ標準になりつつあります。戦闘のヒントの詳細については、[戦闘システムガイド](/en/guides/combat-system-guide/)を参照してください。
