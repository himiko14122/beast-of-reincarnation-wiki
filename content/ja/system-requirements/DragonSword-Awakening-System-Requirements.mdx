ドラゴンソード：覚醒はUnreal Engine 5で構築されており、驚くほど美しい映像を実現しますが、スムーズに動作させるには高性能なPCハードウェアが求められます。ゲームを購入する前に動作要件を理解することで、カクつくフレームレートや長いロード画面といったフラストレーションの蓄積を避けられます。このガイドでは、ドラゴンソード：覚醒の最小、推奨、最適な仕様を網羅し、UE5パフォーマンスにおいて各コンポーネントがなぜ重要なのかを解説し、現在のPCでオービス大陸をプレイできるかどうかを判断する手助けをします。

ゲームは2026年7月22日にSteamでリリースされ、Steamストアページに記載されている動作要件は、ゲームを起動するために必要な最小ハードウェアと、快適なプレイ体験のための推奨ハードウェアの両方を反映しています。しかし、UE5ゲームは「推奨」スペックと真にスムーズなパフォーマンスに必要なハードウェアの間に差があることが多く、特にアセットのストリーミングが発生するオープンワールド環境では顕著です。このガイドでは、各スペックティアにおける実際のパフォーマンスの期待値を提供することで、そのギャップを埋めます。

## 最小動作要件：ゲームを起動する

最小動作要件は、ドラゴンソード：覚醒が起動可能でプレイ可能な最低限のハードウェア構成を表しています。これらのスペックを満たすということはゲームは動作しますが、低いフレームレート、低下した画質、そしてアセットストリーミング時の時折のカクつきが予想されます。

| コンポーネント | 最小要件 |
|-----------|-------------------|
| オペレーティングシステム | Windows 10 64ビット |
| プロセッサー (CPU) | Intel Core i5-8400 / AMD Ryzen 5 2600 |
| グラフィックス (GPU) | NVIDIA GTX 1660 / AMD RX 5600 XT |
| メモリー (RAM) | 8 GB |
| ストレージ | 60 GB（SSDを強く推奨） |
| DirectX | バージョン12 |

最小スペックでは、1080p解像度で低設定時に25〜35 FPSが期待できます。オープンワールドの移動中、UE5のストリーミングシステムが新しいアセットを読み込む際にエリア遷移で時折フレームドロップが発生します。複数の敵やパーティクルエフェクトを含む戦闘では、フレームレートが30 FPSを下回る可能性があり、タイミングベースのタグコンボの実行が困難になります。最小スペックでもゲームはプレイ可能ですが、体験は十分に損なわれるため、少なくともGPUとRAMのアップグレードを強く推奨します。

GTX 1660は2019年製の中級GPUで、ハードウェアレベルのレイトレーシングとDLSSサポートを備えていません。つまり、NVIDIAのアップスケーリング技術を使用してパフォーマンスを向上させることができず、これはUE5ゲームにおいてプレイ可能か不可能かの境界線となることが多いアップスケーリングにおいて大きな不利となります。GPUが最小スペック付近の場合は、[DLSSおよびFSRガイド](/en/system-requirements/dlss-fsr-guide/)で代替のアップスケーリングオプションを確認してください。

## 推奨動作要件：快適なゲームプレイ

推奨仕様は、1080pで中〜高画質設定時に快適な60 FPS体験を実現するために必要なハードウェアを表しています。これはほとんどのプレイヤーが目指すべき目標です。

| コンポーネント | 推奨要件 |
|-----------|----------------------|
| オペレーティングシステム | Windows 10/11 64ビット |
| プロセッサー (CPU) | Intel Core i7-10700 / AMD Ryzen 5 5600X |
| グラフィックス (GPU) | NVIDIA RTX 3060 / AMD RX 6600 XT |
| メモリー (RAM) | 16 GB |
| ストレージ | 60 GB SSD |
| DirectX | バージョン12 |

推奨スペックでは、1080pで高設定時に安定した50〜60 FPSが期待できます。RTX 3060はDLSSをサポートしており、視覚的な品質損失を最小限に抑えながらフレームレートを30〜50%向上させ、ほとんどのシナリオで事実上60 FPSを保証します。Ryzen 5 5600Xは優れたシングルスレッドパフォーマンスを提供しますが、これはオープンワールドの移動中にCPU制限になりやすいUE5ゲームでは重要です。

16 GBのRAM要件は重要です。UE5のオープンワールドゲームはアセットストリーミングに大量のメモリを使用し、8 GBのシステムでは、ゲームがアセットをストレージとの間でページングする際に頻繁なスタッタリングが発生します。GPUが推奨スペックを満たしていても、8 GBのRAMでの動作は体験を損ないます。8 GBから16 GBへのRAMのアップグレードは、ドラゴンソード：覚醒のパフォーマンスにとって最も費用対効果の高い改善の一つです。

### なぜSSDストレージが重要なのか

ストレージ要件は60 GBと記載されていますが、ストレージの種類は非常に重要です。UE5は、オープンワールドを移動中にテクスチャ、ジオメトリ、その他のアセットをオンザフライで読み込むストリーミングシステムを使用しています。従来のHDDでは、このストリーミングにより目に見えるポップイン、スタッタリング、そして長いロード画面が発生します。SSDでは、アセットがほぼ見えないほど高速に読み込まれ、スムーズな体験が生まれます。

60 GBのストレージ見積もりはデモフェーズのもので、ローンチ後のアップデートや追加コンテンツで増加する可能性があります。今後のパッチやDLCファミリアコンテンツを収容するため、少なくとも80 GBの空き容量を確保することを計画してください。ストレージ最適化のヒントについては、[PCパフォーマンスガイド](/en/system-requirements/pc-performance-guide/)を参照してください。

## 最適動作要件：最高の画質

最適仕様は、ドラゴンソード：覚醒を高いフレームレートで最高画質設定で動作させるために必要なハードウェアを表しています。このティアは、可能な限り最高の体験を求めるエンスージアスト向けハードウェアを持つプレイヤー向けです。

| コンポーネント | 最適仕様 |
|-----------|---------------------|
| オペレーティングシステム | Windows 11 64ビット |
| プロセッサー (CPU) | Intel Core i7-13700K / AMD Ryzen 7 7800X3D |
| グラフィックス (GPU) | NVIDIA RTX 4070 / AMD RX 7800 XT |
| メモリー (RAM) | 32 GB |
| ストレージ | 60 GB NVMe SSD |
| DirectX | バージョン12 |

最適スペックでは、1440pで最高設定時に80〜120+ FPS、またはDLSS/FSR有効時に4Kで60+ FPSが期待できます。RTX 4070のDLSS 3フレーム生成機能はさらに高いフレームレートを実現できますが、フレーム生成の視覚的品質はシーンによって varies。32 GBのRAMは、最も要求の厳しいオープンワールドエリアでもアセットストリーミングのスタッタリングをゼロに保証します。

Ryzen 7 7800X3Dは、3D V-CacheのおかげでCPU制限のあるシナリオでパフォーマンスを大幅に向上させるため、UE5ゲームに特に適しています。ドラゴンソード：覚醒や他のUE5ゲームのために専用に新システムを構築する場合、7800X3Dは現在のCPU市場で最高の価格対パフォーマンス比を提供します。

## グラフィック設定のパフォーマンスへの影響

UE5ゲームは、パフォーマンスに大きな影響を与える幅広いグラフィック設定を提供します。どの設定が最大のインパクトを持つかを理解することで、ハードウェアに基づいて調整の優先順位を決めるのに役立ちます。

### 影響度の高い設定

- **Lumenグローバルイルミネーション**：UE5の動的グローバルイルミネーションシステムは、単独で最も要求の厳しいグラフィック設定です。Lumenを「高」から「中」に下げることで、視覚的な品質損失を最小限に抑えながらフレームレートを15〜25%向上させることができます。「低」に下げるとレイトレースされたGIが完全に無効化され、さらに15〜20%の改善が得られますが、ライティングのリアリズムが大幅に低下します。

- **バーチャルシャドウマップ**：UE5のシャドウシステムは2番目に要求の厳しい設定です。シャドウ品質を「Epic」から「高」に下げると、パフォーマンスが10〜15%向上します。これは、ライティングの視覚的品質を犠牲にせずにより高いフレームレートを求める場合に適した設定です。

- **描画距離**：詳細なジオメトリがどの遠さまで描画されるかを制御します。描画距離を「Epic」から「高」に下げると、オープンワールドエリアでパフォーマンスが5〜10%向上します。ダンジョンでは、この設定の影響は最小限です。

### 影響度の低い設定

- **テクスチャ品質**：十分なVRAM（8 GB以上）がある場合、フレームレートへの影響は最小限です。VRAM関連のスタッタリングが発生している場合にのみテクスチャを下げてください。

- **ポストプロセッシング品質**：中程度の影響（低とEpicの間に5〜10%の差）。パフォーマンスが境界線上にある場合、これを下げると効果的です。

- **モーションブラー**：パフォーマンスへの影響がほぼない個人的な好み設定です。カメラ移動中のよりシャープな映像を好む場合は無効にしてください。

詳細なパフォーマンス最適化戦略については、[PCパフォーマンスガイド](/en/system-requirements/pc-performance-guide/)を参照してください。

## マルチGPUおよびSLI/CrossFireサポート

ドラゴンソード：覚醒はSLIまたはCrossFireマルチGPU構成をサポートしていません。ほとんどの最新のUE5ゲームと同様に、エンジンは単一GPUで動作するように設計されており、2つ目のGPUを追加してもパフォーマンス上の利点はありません。マルチGPUシステムの場合、ゲームはプライマリGPUのみを使用します。プレイする前にGPUコントロールパネルでSLIまたはCrossFireを無効にして、潜在的なドライバの競合を避けてください。

統合GPUとディスクリートGPUの両方を搭載したノートPCユーザーは、ゲームが統合GPUではなくディスクリートGPUで動作していることを確認してください。NVIDIA OptimusノートPCは、VR以外のアプリケーションで統合GPUをデフォルトにすることがあり、結果としてプレイ不可能なパフォーマンスになります。ゲーム実行ファイルを右クリックし、「グラフィックスプロセッサーで実行 > 高性能NVIDIAプロセッサー」を選択してディスクリートGPUを強制してください。ノートPC最適化のヒントの詳細については、[PCパフォーマンスガイド](/en/system-requirements/pc-performance-guide/)を参照してください。

## サポート言語と地域に関する考慮事項

ドラゴンソード：覚醒はSteamで11言語をサポートしており、これはほとんどのアクションRPGよりも幅広い言語選択です。サポートされている言語は、英語、韓国語、日本語、ドイツ語、フランス語、ポルトガル語（ブラジル）、スペイン語、簡体字中国語、繁体字中国語、ロシア語、タイ語です。すべてのサポート言語に完全なテキスト翻訳が含まれますが、ボイスアクトは主に韓国語で、日本語と英語のオプションがあります。

言語の選択は動作要件に影響しません。ただし、CJK（中国語、日本語、韓国語）でプレイする場合、オペレーティングシステムに適切な言語パックがインストールされていることを確認してください。言語パックが欠落していると、一部のUE5ゲームでテキスト表示の問題が発生することがあります。

## FAQ

### ドラゴンソード覚醒はノートPCで動作しますか？

はい、ただしパフォーマンスはノートPCのGPUに大きく依存します。RTX 3060モバイルGPU以上のゲーミングノートPCは推奨設定でゲームを動作させることができますが、ノートPC用GPUはサーマルスロットリングのため、デスクトップ版と比較して通常15〜25%遅く動作します。専用GPUを搭載していない薄型軽量ノートPCは、最小要件を満たすのにも苦労するでしょう。ノートPC固有の最適化のヒントについては、[PCパフォーマンスガイド](/en/system-requirements/pc-performance-guide/)を参照してください。

### 8 GBのRAMは本当にゲームの実行に十分ですか？

技術的には8 GBは最小仕様を満たしますが、体験は損なわれます。UE5オープンワールドゲームは、アセットストリーミングのためにメモリを多く消費します。8 GBの場合、エリア遷移中の頻繁なマイクロスタッタリングと長いロード画面が予想されます。16 GBへのアップグレードはこのゲームにとって最も影響のあるアップグレードであり、GPUやCPUのアップグレードと比較して比較的低コストです。[PCで動作可能かガイド](/en/system-requirements/can-my-pc-run-it/)でより具体的なハードウェアガイダンスを確認してください。

### ゲームはウルトラワイドモニターをサポートしていますか？

ドラゴンソード：覚醒は標準の16:9解像度をネイティブにサポートします。ウルトラワイド（21:9および32:9）のサポートは公式には確認されておらず、UE5ゲームでは非標準アスペクト比でUIスケーリングの問題が発生することがよくあります。ゲームはウルトラワイド解像度で動作する可能性がありますが、UIのクリッピングや要素の歪みの可能性があります。ウルトラワイドディスプレイを使用する場合は、コミュニティフォーラムで非公式のウルトラワイドパッチを確認してください。

### ストレージ要件はローンチ後に増加しますか？

はい、ローンチ後のアップデート、追加のヒーローコンテンツ、潜在的なDLCにより、総ストレージ要件が増加します。60 GBという数字はデモフェーズのもので、ローンチ時のベースゲームに適用されます。ゲームの全ライフサイクルに対応する最低80〜100 GBのストレージを確保してください。これには、ロードマップで発表された4人のローンチ後ヒーロー（Liza、Jerome、Veronica、Logan）とリフトシステムの拡張が含まれます。

### ドラゴンソード覚醒はレイトレーシングをサポートしていますか？

UE5のLumenシステムは、グローバルイルミネーションと反射のためにソフトウェアベースのレイトレーシングを提供し、中以上のグラフィック設定で有効になります。ハードウェアアクセラレーションによるレイトレーシング（Nanite + RT反射）は別のトグルとして利用可能な場合がありますが、パフォーマンスに大きな影響を与えます。RTX 3060推奨スペックは中設定でのLumenを処理できますが、フルハードウェアレイトレーシングでは苦戦する可能性があります。UE5レンダリング機能の詳細については、[DLSSおよびFSRガイド](/en/system-requirements/dlss-fsr-guide/)を参照してください。
