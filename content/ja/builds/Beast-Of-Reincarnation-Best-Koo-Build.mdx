## Kooのコアメカニズムとステータス優先度の理解

特定の装備について詳しく説明する前に、Kooの特性について理解することが重要です。なぜなら、彼女のキットはユニークな方法でスケールし、汎用的なビルドでは十分に機能しないからです。Kooのアビリティは主に**攻撃力**と**クリティカルダメージ**でスケールしますが、彼女のシグネチャーパッシブである**Shadow Resonance**は、彼女のクリティカルヒットの一部を敵の防御を無視するトゥルーダメージに変換します。これが、クリティカルを積まずに生の攻撃力だけを重ねても彼女の上限を引き出せない理由です。コミュニティのテストによれば、エンドゲームコンテンツにおける理想的なステータス比率は、**速度**を最低145に保ちながら、攻撃力対クリティカルダメージを2:1の比率にすることを目標とすることです。これにより、彼女はほとんどのボスより先に行動できます。

| ステータス優先度 | 目標値（エンドゲーム） | 重要性 |
| :--- | :--- | :--- |
| **攻撃力** | 3,200以上 | すべてのアビリティの基本スケール |
| **クリティカルダメージ** | 180%以上 | Shadow Resonanceのトゥルーダメージを増幅 |
| **速度** | 145以上 | 先制行動の優位性を確保 |
| **効果命中率** | 55%以上 | デバフ適用の保証 |

多くのプレイヤーが当初は純粋に攻撃力に注目しますが、本当の力の急成長は、**クリティカルダメージ**と**速度**の両方のクリティカルな閾値に到達した時に訪れます。これにより、彼女は優先ターゲットが行動する前にそれらを排除できます。さまざまなプレイヤーレポートから収集されたコミュニティのコンセンサスは、速度を軽視すると、彼女が攻撃ステータスの高い投資を活用する前にKooが crowd control されたりバーストダウンされたりする結果になりやすいことを強調しています。

### PvE vs PvPのステータス閾値

高レベルのPvEステージをクリアしているのか、アリーナで競争しているのかによって、Kooのビルド方法は大きく異なります。PvEでは、敵が予測可能なパターンに従うため、生のダメージのために速度を少し犠牲にすることができます。しかし、PvPでは、最初の crowd control に抵抗することが重要であるため、**速度**と**効果抵抗**がプレミアムステータスになります。

- **PvEビルドフォーカス：** 攻撃とクリティカルダメージを積極的に優先します。速度135でほとんどのストーリーモードのボスには十分です。
- **PvPビルドフォーカス：** 一般的な開幕を上回るために速度160以上を目指します。最初のターンでスタンや沈黙を受けないように、**効果抵抗**に少なくとも40%を投資します。

## 上級戦闘ローテーションとスキルアップグレード

最適なスキルローテーションを理解することが、良いKooと素晴らしいKooを区別するものです。なぜなら、バフされていないアビリティでターンを浪费すると、全体的なダメージ出力が低下するからです。シングルターゲットボス戦のコアルーテーションは、彼女のセカンドスキル**Shadow Mark**を開いて防御ブレイクを適用し、続いて彼女のサードスキル**Eclipse Strike**を即座に使用します。これは、マークされたターゲットに massive なボーナスダメージを与えます。彼女は低HPの敵を片付ける場合やクールダウンを待っている場合にのみ基本攻撃を使用すべきです。なぜなら、彼女のアクティブアビリティと比較してダメージ損失が significant だからです。

- **ボスローテーション：** Shadow Mark → Eclipse Strike → 基本攻撃（繰り返し）
- **範囲攻撃の周回：** Shadow Mark（中央の敵に）→ **Abyssal Wave**（スキル1）→ Eclipse Strike（生き残りに）
- **PvPバースト：** 味方から速度バフ → Shadow Mark → Eclipse Strike（敵のキャリーに）

彼女のスキルのアップグレード優先度も同様に重要です。生のダメージスケーリングのために最初に**Eclipse Strike**を最大化し、続いて防御貫通値を増加させるために**Shadow Mark**を最大化します。彼女の基本攻撃は最後の優先度にすべきです。なぜなら、彼女のアクティブスキルのユーティリティとバーストと比較して、ダメージの増加は最小限だからです。コミュニティデータによれば、完全にアップグレードされた**Eclipse Strike**は、彼女の攻撃力の300%以上をダメージとして与えることができます。これが、**クリティカルダメージ**の閾値に到達することが非常に重要な理由です。

**Eclipse Fang武器を入手するにはどうすればよいですか？**

**クリティカル率が低い場合、どのスピリットストーンを使用すべきですか？**

100%のクリティカル率に到達するのに苦労している場合は、2ピースの**Critical Set**と**Veil of Darkness**の兜を組み合わせて使用すべきです。これにより、**クリティカルダメージ**への投資を価値あるものにするのに十分なクリティカルチャンスが得られます。これは、**Beast of Reincarnation ベストスピリットストーン**のジレンマに対する一般的な早期ゲームの解決策です。

**ブーツでは速度と攻撃力のどちらが重要ですか？**

Kooにとって、**速度**はブーツで最も重要なステータスです。なぜなら、敵チームより先に行動することで、**Shadow Mark**を適用し、ターゲットが反応する前にバーストダウンできるからです。攻撃力%は、速度が確保された後に探すべきセカンダリステータスです。

**Kooはタンクとして機能できますか？**

いいえ、Kooは純粋なダメージディーラーであり、決してタンクとしてビルドすべきではありません。なぜなら、彼女の基本防御ステータスは持続的なフォーカスファイアを生き残るには低すぎるからです。彼女は、敵を迅速に殺すか、Emmaのような専用のサポートに生き延びることに依存しています。
