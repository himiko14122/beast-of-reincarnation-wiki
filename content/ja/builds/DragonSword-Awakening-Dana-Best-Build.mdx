## ダナの氷霜ゲージの仕組みを理解する

氷霜ゲージは、ダナが凍結を付与する能力を司るリソースです。ダナの体力バーの下に表示される視覚的なメーターで、敵に攻撃を命中させることで0%から100%まで蓄積されます。攻撃の種類によって氷霜ゲージへの蓄積量は異なります。通常攻撃は1ヒットあたり約5%、「アイスランス」スキルは15%、範囲攻撃スキル「グレイシャルバラージ」はクールダウンが長いものの20%を蓄積します。氷霜ゲージが100%に達すると、ダナの次の攻撃が自動的に敵に凍結を付与します。

ここで重要な点は、ダナが積極的に攻撃していない場合、氷霜ゲージは時間経過とともにゆっくりと減少することです。つまり、ゲージを100%まで溜めて無期限に温存することはできません。ダナが待機中の場合、減少速度は1秒あたり約2%です。つまり、他の英雄を使用している場合、満タンのゲージは約50秒で完全に空になります。スキルツリーへの投資によってこの減少速度を大幅に遅くすることができ、これはダナのビルドにおいて最も重要な選択の一つです。

ダナの氷のゴーレムであるチャコは、独自の小型氷霜ゲージを持っており、チャコが敵を攻撃すると独立して蓄積されます。チャコはプレイヤーの入力なしに自動的に攻撃を行います。チャコの小型ゲージが100%に達すると、最も近い敵に凍結スタックを付与します。チャコによるこの凍結スタックは、ダナ自身の凍結付与とは別に扱われます。つまり、最適なプレイでは、二つの発生源から短時間に連続して凍結を発動させることが可能です。

### 氷霜ゲージ蓄積量の内訳

以下の表は、基本値におけるダナの各アクションのおおよその氷霜ゲージ蓄積量を示しています。

| アクション | 氷霜ゲージ蓄積量 | クールダウン |
|--------|-------------------|----------|
| 通常攻撃 (1ヒットあたり) | 5% | なし |
| アイスランス スキル | 15% | 6秒 |
| グレイシャルバラージ スキル | 20% | 12秒 |
| チャコの自動攻撃 | 8% (チャコゲージ) | 3秒 |
| タグイン攻撃 | 10% | タグイン毎 |

ビルドに投資していない場合、ダナが氷霜ゲージを0%から100%まで溜めるには約8～10秒の連続攻撃が必要です。ビルドに投資することでこれを4～5秒に短縮でき、この水準に達することでダナはスタンロックの要として機能するようになります。

## スタンロックダナビルド：永久凍結アーキタイプ

スタンロックダナビルドは、氷霜の錬金術師にとって最も人気があり効果的なビルドです。氷霜ゲージ蓄積速度、凍結持続時間、ゲージ減少抑制に投資することで、凍結の有効時間を最大化します。目標は、ダナが凍結の持続時間よりも早く凍結を付与できる状態に到達し、永続的な群集制御を実現することです。

### スタンロックダナのスキルツリーパス

以下の優先順位でスキルポイントを割り振ります。

1.  **氷霜ゲージ蓄積速度 (5ランク)** — すべての攻撃が氷霜ゲージを蓄積する速度をランクごとに8%増加させます。最大ランクでは、ゲージ蓄積速度が40%増加し、ゲージが満タンになるまでの時間が約10秒から6秒に短縮されます。これはダナのどのビルドにおいても最も重要なノードです。
2.  **凍結持続時間延長 (5ランク)** — 凍結の基本持続時間をランクごとに0.3秒延長します。最大ランクでは、凍結持続時間がさらに1.5秒延長されます。装備やファミリアーによる他の持続時間延長と組み合わせることで、タグローテーション全体を維持するのに十分な凍結時間を確保できます。
3.  **氷霜ゲージ減少抑制 (4ランク)** — ダナが待機中に氷霜ゲージが減少する速度をランクごとに15%抑制します。最大ランクでは減少速度が60%抑制されるため、待機中に満タンのゲージが約80秒持続するようになります（通常は50秒）。これにより、タグローテーションのタイミングに大幅な柔軟性が生まれます。
4.  **グレイシャルウォール (3ランク)** — 凍結を発動するために必要な氷霜ゲージの閾値を100%から80%に引き下げます。最大ランクでは、ダナは80%のゲージで凍結を付与できるようになり、凍結閾値に達するまでの攻撃回数が少なくて済みます。事実上、蓄積時間を20%短縮するため、非常に強力なノードです。
5.  **チャコ強化 (3ランク)** — チャコの攻撃速度と氷霜ゲージ蓄積速度をランクごとに10%増加させます。これによりチャコの小型ゲージがより早く溜まり、より頻繁に二次的な凍結発動が期待できます。
6.  **状態異常重複：凍結延長 (2ランク)** — 他の状態異常が有効な時に凍結を付与すると、凍結持続時間がさらに15%延長されます。リュートの「ノックダウン」やキャステラの「エアボーン」と相乗効果を発揮し、複合的な群集制御を実現します。

合計投資ポイントは22で、ゲームをかなり進行させる必要があります。上記の最初の3つのノードに少なくとも14ポイント投資した時点で、ダナは完全なスタンロックの要として機能し始めます。

### スタンロックダナの装備

スタンロックダナの武器選択は、氷霜ゲージ蓄積速度に受動的ボーナスを提供する「グレイシャルスタッフ」系統が中心となります。深海探索エリアで入手できる「深淵のグレイシャルスタッフ」は、クリティカルヒット時に通常の蓄積に加えて5%の氷霜ゲージ蓄積を追加するため、最適な武器です。ダナのクリティカル率は適切な装備で約25%まで構築できるため、この武器は事実上、蓄積速度をさらに15～20%向上させます。

防具は状態異常持続時間と生存性を優先します。頭装備「グレイシャルサークレット」は凍結持続時間を15%延長し、スキルツリーの持続時間延長と重複して、合計の凍結持続時間を大幅に伸ばします。「フロストウィーブローブ」はダナがフィールドに出ている間、被ダメージを10%軽減するパッシブを提供します。凍結状態を維持するために他の英雄よりも長く活動し続ける必要があるダナにとって、これは重要です。「エントロピーガントレット」はすべての状態異常持続時間を10%延長し、凍結をさらに長くします。

スタンロックダナのアクセサリーには「チェインブレイカーメダリオン」があり、対象に他の状態異常が有効な場合、凍結に必要な氷霜ゲージの閾値をさらに5%引き下げます。スキルツリーの「グレイシャルウォール」ノードと組み合わせることで、パーティ編成においてダナはわずか75%のゲージで凍結を発動できるようになります。これは大幅な効率向上です。

### スタンロックダナのファミリアー

「フロストウィスプ」ファミリアーは、スタンロックダナにとって必須の組み合わせです。そのパッシブ能力「永久凍土の絆」は、ダナが待機中でも5秒ごとに氷霜ゲージを3%蓄積します。つまり、リュートやキャステラを操作している間も、ダナのゲージは受動的に蓄積され続けます。氷霜ゲージ減少抑制のスキルツリーノードと組み合わせることで、フロストウィスプはダナにタグバックした際に常にゲージが部分的に溜まっている状態を効果的に保証します。

「アビサルダイアウルフ」ファミリアーは、状態異常の付与速度にわずかなパッシブブーストを提供する第二の選択肢です。2026年8月の購入特典でアビサルダイアウルフを入手した場合、野生でフロストウィスプを見つける前のゲーム序盤において、その代用として使用できます。機能的な差はわずかです。スタンロックダナに特化した場合、フロストウィスプの方が約10%効果的ですが、アビサルダイアウルフは万能で堅実な選択肢です。

## DPSダナビルド：氷霜ダメージの代替案

スタンロックがダナの主要なアーキタイプですが、DPSに特化したダナビルドも有効です。このビルドは群集制御の最適化よりも、ダナの「アイスランス」や「グレイシャルバラージ」スキルの純粋なダメージを最大化します。ダナのダメージ倍率はリュートやロキシーのような専用DPS英雄よりも低いため、DPSダナビルドはスタンロックほど人気がありませんが、凍結の有用性が低い特定のコンテンツでは効果的です。

### DPSダナのスキルツリーパス

1.  **アイスランスダメージ倍率 (5ランク)** — 「アイスランス」のダメージをランクごとに8%増加させます。最大ランクでは、アイスランスのダメージが40%増加します。
2.  **グレイシャルバラージ範囲拡大 (3ランク)** — 「グレイシャルバラージ」の効果範囲をランクごとに15%拡大し、より多くの敵に同時に命中させます。
3.  **氷霜ゲージ蓄積速度 (3ランク)** — DPSビルドであっても、凍結発動はダメージに貢献し、攻撃の機会を生み出すため、ゲージ蓄積速度は重要です。
4.  **氷スキルのクリティカル率 (3ランク)** — すべての氷属性スキルにクリティカル率を追加し、平均ダメージ出力を向上させます。
5.  **チャコダメージ強化 (2ランク)** — チャコの攻撃ダメージを増加させ、DPS源として貢献させます。

DPSダナは、既にスタンロックパーティを持っており、群集制御の重要性が低いコンテンツ用のセカンダリビルドを求めるプレイヤーにのみ推奨されます。ほとんどのプレイヤーにとって、スタンロックダナの方がより強力で汎用性の高い選択肢です。

## タグコンボ編成におけるダナの役割

どのようなパーティ編成においても、ダナの主な役割は凍結の要となることです。リュートとキャステラを含む標準的なスタンロックパーティでは、ダナが凍結で群集制御チェーンを開始し、リュートにタグしてノックダウン、キャステラにタグしてエアボーンへと繋ぎます。ローテーションは以下の通りです。

1.  ダナが氷霜ゲージを溜める → 凍結を付与 → リュートにタグ。
2.  リュートがノックダウンを付与（凍結と重複 → 持続時間延長） → キャステラにタグ。
3.  キャステラがエアボーンを付与（ノックダウンと重複 → 持続時間延長） → ダナにタグ。
4.  ダナがエアボーン終了前に凍結を再付与 → サイクル継続。

重要なタイミングはステップ4です。キャステラのエアボーンが終了する前に、ダナが凍結を再付与しなければなりません。凍結持続時間と氷霜ゲージ蓄積速度に完全に投資していれば、このタイミングは余裕を持って行えます。十分に投資していない場合、猶予は狭く練習が必要です。パーティ編成戦略の詳細については、[パーティ編成ガイド](/ja/guides/team-composition-guide/)をご覧ください。

## FAQ

### スタンロック編成を使わない場合でも、ダナを育成する価値はありますか？

はい、ただし優先度は下がります。DPS重視のパーティであっても、ダナの凍結は他の英雄に安全な攻撃機会を生み出す貴重な群集制御を提供します。完全なスタンロックの要として構築する必要はなく、氷霜ゲージに中程度の投資をしただけのダナでも、大きなユーティリティを提供します。ただし、群集制御を全く必要としない純粋なDPSパーティを運用している場合、ダナの貢献はロキシーのような専用DPS英雄よりも小さくなります。DPS英雄の代替案については、[最強ビルドガイド](/ja/builds/best-builds-guide/)をご確認ください。

### チャコはダナの氷霜ゲージとどのように連携しますか？

チャコは独自の小型氷霜ゲージを持っており、チャコの自動攻撃によって蓄積されます。チャコのゲージが100%に達すると、最も近い敵に凍結スタックを付与します。チャコからのこの凍結スタックは、ダナ自身の氷霜ゲージとは別のものです。チャコはダナのゲージに貢献せず、ダナもチャコのゲージに貢献しません。しかし、両方の発生源が同じ敵に凍結を付与することができ、その場合、凍結持続時間は加算されます。つまり、タイミングよくチャコの凍結とダナの凍結を重ねることで、通常の2倍の時間、敵を拘束できます。

### ダナの凍結はすべてのボスに有効ですか？

ドラゴンソード：覚醒のほとんどのボスは凍結の影響を受けますが、一部のベリーハードボスは状態異常耐性を持っており、凍結持続時間を50%短縮します。これらのボスは依然として凍結させることができますが、凍結時間が短く、スタンロックのローテーションをより厳密に行う必要があります。エンドゲームコンテンツの特定の少数のボスは凍結に完全耐性を持っており、これらの戦闘ではスタンロックダナの効果は低下します。これらのボスに対しては、DPSダナビルドまたは代替の群集制御英雄が推奨されます。

### ダナにとって最適なパーティ編成は何ですか？

ダナにとって最も強力な編成は、ダナ + リュート + キャステラです。これは3つの異なる状態異常（凍結、ノックダウン、エアボーン）を重ねて継続的な群集制御を提供します。代替編成としては、感電/凍結/ノックダウンをカバーするダナ + ジョニー + リュートや、DPSと制御のハイブリッド編成であるダナ + ロキシー + キャステラなどがあります。重要な原則は、ダナの凍結が最大の効果を発揮するために、少なくとも1つの他の群集制御状態異常と重なることです。この編成のもう半分の詳細については、[キャステラ最強ビルドガイド](/ja/builds/castella-best-build/)をご覧ください。

### ダナのビルドに必要な「名もなき魂」はどうやって集めますか？

名もなき魂は、ダンジョンボスからのドロップや英雄リクエストの完了によって入手できます。ベリーハードダンジョンは1回の完了につき3～5個と最も高いドロップ率を誇ります。また、次元の狭間システムもマイルストーン報酬として名もなき魂を提供します。ダナのビルドでは、完全なスタンロック投資に22スキルポイントが必要です。つまり、ゼロから始める場合、約22個の名もなき魂が必要になります。これは、定期的なエンドゲーム周回を2～3週間続ければ達成可能な数です。より効率的な周回ルートについては、[名もなき魂ガイド](/ja/cooking-crafting/nameless-soul-guide/)をご覧ください。
