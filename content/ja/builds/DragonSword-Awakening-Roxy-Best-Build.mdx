DragonSword: Awakeningの二刀流アサシン、ロキシーは、ゲーム最高の出血スペシャリストであり、正しく構築すれば最もプレイしていて楽しいヒーローの一人です。彼女の戦闘は、持続ダメージを与える唯一の状態異常である「出血」を中心に展開されます。これにより、ロキシーは敵を無力化するために状態異常を使うリュート、ダナ、カステラといったヒーローとは根本的に異なります。ロキシーは出血を使って敵を倒します。ゆっくりと、しかし確実に。その間、タッグパートナーが群衆制御を担当します。

このガイドでは、ロキシーの二つの有効なビルドアーキタイプを解説します。出血を急速に蓄積させてシグナルスキルのダメージを最大化する「出血DPSバーストビルド」と、出血の持続時間とスタック数を延長し、消耗戦を仕掛ける「DOT持続ダメージビルド」です。スキルツリー、装備、使い魔の組み合わせ、タグコンボのローテーションを詳細に分析し、あなたのプレイスタイルやコンテンツに最適なロキシービルドを選べるようにします。

## ロキシーの中核メカニズム：出血と二刀流システム

ロキシーの主要な状態異常は出血で、持続時間中、毎秒固定ダメージを与えます。敵を無力化する他の状態異常とは異なり、出血は純粋に攻撃的です。攻撃を中断させたり、移動を妨げたり、スキルを無効化したりすることはありません。出血が強力なのは、そのスタック性にあります。同じ敵に複数の出血を同時に付与でき、各スタックは独立して毎秒ダメージを与えます。単一の敵に8スタックの出血を付与したロキシーは、基本出血ダメージの8倍のダメージを毎秒与えることになり、これは莫大な持続ダメージとなります。

ロキシーの二刀流システムは、各基本攻撃入力で二度攻撃することを意味します。それぞれの攻撃は独立して出血の閾値に寄与します。ビルドに投資しない場合、出血は6ヒット（基本攻撃3回×二刀流）後に発動します。これはリュートの基本5ヒット閾値より遅く、ロキシーの二刀流攻撃が一撃あたりのダメージは低いものの、秒間ヒット数が多いことを反映しています。

もう一つの重要なメカニズムは、ロキシーのシグナルスキル「クリムゾンスパイラル」です。出血が発動すると、クリムゾンスパイラルが回転する二刀流攻撃として発動し、短時間に複数回のヒットを与えます。スキルツリーの「ヘモリッジ」ノードに投資している場合、クリムゾンスパイラルの各ヒットは追加の出血スタックを付与する可能性があります。つまり、一度のクリムゾンスパイラルで3～5の出血スタックを追加でき、ダメージの蓄積を劇的に加速させます。

### 出血スタックあたりのダメージ

出血1スタックの基本ダメージはロキシーの攻撃力に依存します。典型的なゲーム中盤の数値では、出血1スタックはロキシーの攻撃力の約2%のダメージを毎秒、6秒間与えます。これは、1スタックがその持続時間全体で、攻撃力の約12%の総ダメージを与えることを意味します。8スタックの場合、6秒間の総出血ダメージは攻撃力の約96%に達します。これは通常攻撃やシグナルスキルのダメージに加えての数値です。

## 出血DPSバーストビルド：最大スタック速度

出血DPSバーストビルドは、ロキシーの最も人気のあるアーキタイプです。出血スタックの付与速度と、シグナルスキル「クリムゾンスパイラル」のダメージを最大化します。目標は、可能な限り迅速に最大出血スタックに到達し、戦闘全体を通してそれを維持し、リュートのノックダウンベースのDPSに匹敵するかそれを超える持続的なバーストダメージを与えることです。

### 出血DPSバーストロキシーのスキルツリー

以下の優先順位でスキルポイントを投資します：

1.  **ヘモリッジ（5ランク）** — シグナルスキル「クリムゾンスパイラル」の各ヒットは、ランクごとに15%の確率で追加の出血スタックを付与します。最大ランクでは、クリムゾンスパイラルの各ヒットが75%の確率で追加の出血スタックを付与します。クリムゾンスパイラルは約6～8回ヒットするため、シグナルスキル発動ごとに4～6の出血スタックが追加され、スタック蓄積が劇的に加速します。
2.  **ラピッドインシジョン（5ランク）** — 出血発動に必要なヒット数を6から3に減少させます。これはリュートの「スタガリングブロウ」に相当するロキシーのノードで、クリムゾンスパイラルをより頻繁に発動できるようになるため、DPSに最も影響を与える単一のノードです。
3.  **クリムゾンスパイラルダメージ倍率（4ランク）** — クリムゾンスパイラルの基本ダメージをランクごとに10%増加させます。最大ランクではクリムゾンスパイラルのダメージが40%増加し、ヘモリッジを通じて付与される出血スタックのダメージも間接的に増加します。
4.  **出血ダメージ/ティック（3ランク）** — 各出血スタックの毎秒ダメージをランクごとに8%増加させます。最大ランクでは各スタックの毎秒ダメージが24%増加し、6～8スタックがアクティブな場合、これは大きなブーストとなります。
5.  **スイッチングシグナルウィンドウ延長（2ランク）** — クリムゾンスパイラル後のタグウィンドウをランクごとに0.3秒延長します。出血は敵を無効化しませんが、スイッチングシグナルウィンドウは他のヒーローとのタグコンボチェーンを維持するために依然として重要です。

合計投資ポイントは19です。残りのポイントは、生存性向上や出血持続時間延長などのマイナーノードに振り分けます。

### 出血DPSバーストロキシーの装備

DPSバーストロキシーの武器選択は、出血ダメージへのパッシブボーナスを提供する「クリムゾンブレード」系統が中心です。「深淵のクリムゾンブレード」は「クリムゾンホロウ」ダンジョンで入手でき、出血のティックダメージを15%増加させ、通常の閾値とは独立して、任意のヒットに10%の確率で出血を付与するため、最適な武器です。これにより、ランダム発動が発生すれば、ロキシーはわずか2回の基本攻撃で出血を発動できる可能性があります。

防具は攻撃力と出血強化を優先します。「ブラッドレターのベスト」はクリムゾンスパイラルのダメージを10%増加させ、「レイザーガントレット」は出血関連攻撃のクリティカル率を増加させます。アクセサリースロットには「ベルセルクの指輪」を装備すべきです。これはアクティブな状態異常の数に基づいてシグナルスキルダメージを増加させます。ロキシーは6～8の出血スタックを維持するため、この指輪はクリムゾンスパイラルに多大なダメージブーストを提供します。

### 出血DPSバーストロキシーの使い魔

「シャドーウィーゼル」の使い魔は、DPSバーストロキシーにとって最適な組み合わせです。そのパッシブ能力「長引く傷」は、各出血スタックの持続時間を15%延長します。これにより、出血スタックの基本持続時間が約6秒から約7秒になります。これにより、スタックが切れる前に再付与するための時間が長くなり、6～8スタックの維持が著しく容易になります。

「スパイダー」の使い魔は、出血に加えて毒効果を追加し、追加のDOTダメージを提供する代替案です。毒は出血のようにタグコンボシステムと相互作用しませんが、総ダメージ出力に貢献します。スパイダーは、最大限の純粋なダメージが必要で、タグコンボシステムの群衆制御の側面がそれほど重要でないコンテンツに推奨されます。

### 出血DPSバーストロキシーのタグコンボローテーション

ロキシーのDPSバーストローテーションは、出血スタックを最大化し、クリムゾンスパイラルを可能な限り頻繁に発動させるように設計されています：

1.  基本攻撃3回（合計6ヒット）で出血を発動 → クリムゾンスパイラルが発動。
2.  クリムゾンスパイラル中に、ヘモリッジが4～6の追加出血スタックを付与。
3.  スイッチングシグナルウィンドウ中に、ダナにタグ → ダナが凍結を付与 → スイッチングシグナルが発動。
4.  リュートにタグ → リュートがノックダウンを付与 → スイッチングシグナルが発動。
5.  ロキシーにタグバック → 基本攻撃3回 → 出血を再発動 → クリムゾンスパイラルが再び発動。
6.  戦闘全体を通して6～8の出血スタックを維持。

このローテーションでは、出血スタックのタイマーに注意を払う必要があります。既存のスタックが切れる前にロキシーにタグバックしなければ、蓄積したダメージを失います。タグコンボのメカニズムの詳細については、[上級タグコンボガイド](/en/tag-combos/advanced-tag-combos/)を参照してください。

## DOT持続ダメージビルド：持続的な消耗戦の選択肢

DOT持続ダメージビルドは、バーストダメージを犠牲にして最大限の持続的な消耗を狙います。急速に出血を蓄積させる代わりに、このビルドは出血の持続時間を延長し、各スタックのダメージを最大化します。目標は、出血を一度付与し、長時間持続させ、出血がアクティブな間にタグコンボで戦場を制御することです。

### DOT持続ダメージロキシーのスキルツリー

1.  **出血持続時間延長（5ランク）** — 各出血スタックの基本持続時間をランクごとに0.8秒延長します。最大ランクでは、出血は6秒ではなく10秒持続し、スタックを維持するための時間が大幅に長くなります。
2.  **ヘモリッジ（4ランク）** — 優先順位はスタック速度ではなく持続時間であるため、DPSバーストビルドよりランクは少なめです。4ランクでも、クリムゾンスパイラルのヒットごとに60%の確率で追加スタックを付与します。
3.  **出血ダメージ/ティック（5ランク）** — スタックあたりのダメージに最大投資。最大ランクでは、各スタックの毎秒ダメージが40%増加します。
4.  **ラピッドインシジョン（2ランク）** — ヒット閾値を6から4に減少させます。DOT持続ダメージビルドは急速な付与ではなく持続時間の延長に依存するため、DPSバーストより投資は少なめです。
5.  **出血拡散（3ランク）** — 敵に出血が付与されている状態でクリムゾンスパイラルが発動すると、近くの敵がランクごとに20%の確率で出血1スタックを受けます。最大ランクでは、クリムゾンスパイラルは付近のすべての敵に出血を拡散でき、DOT持続ダメージビルドは集団戦で非常に優れたものになります。

合計投資ポイントは19です。DOT持続ダメージビルドは、出血拡散によってすべての敵に同時にダメージを与えるDOTカスケードを発生させられる、複数の敵がいる戦闘で真価を発揮します。

### DOT持続ダメージロキシーの装備

「リーチストーンリング」はDOT持続ダメージロキシーの中核アクセサリーです。出血のティックがダメージを与えるたびに、ロキシーの最大HPの1%を回復します。複数の敵に6～8スタックの出血がある場合、これは大幅なパッシブサステインを提供し、ロキシーがより長く戦場に留まることを可能にします。「クリムゾンブレード」は純粋な出血ダメージボーナスのために依然として良い武器選択であり、「ブラッドレターのベスト」はクリムゾンスパイラルのダメージ強化を提供します。

## ロキシーのチーム編成に関する考察

ロキシーは、彼女がダメージを与えている間に他のヒーローが群衆制御を提供するチーム編成で最も効果を発揮します。出血は敵を無力化しないため、ロキシーが安全に出血スタックを付与し維持するためには、タッグパートナーが群衆制御を担当する必要があります。最強のロキシーチームはダナ + リュート + ロキシーで、ダナが凍結、リュートがノックダウン、ロキシーが出血による持続DPSを提供します。

代替チームとしてカステラ + ダナ + ロキシーがあり、これはリュートのノックダウンをカステラの浮かしと交換します。このチームは群衆制御の持続時間は長いですが、カステラの浮かしはノックダウンのように出血と相互作用しないため、タグコンボのシナジーはわずかに低下します。これらの編成の選択は、どのヒーローに投資しているかによって異なります。

## FAQ

### DPSとしてロキシーはリュートより優れていますか？

遭遇する敵によります。リュートのDPSバーストビルドは、シグナルスキルを急速に発動できる短時間の戦闘でより高いダメージを与えます。ロキシーの出血DPSは、出血スタックが時間とともに蓄積されるため、長時間の戦闘でより強力です。60秒以上続くボス戦では、通常ロキシーがリュートを上回るダメージを与えます。短い戦闘では、リュートの方が効率的です。詳細な比較については、[最強ビルドガイド](/en/builds/best-builds-guide/)を参照してください。

### ロキシーは同時にいくつの出血スタックを維持できますか？

理論上の最大値は無制限ですが、実際には、初期のスタックが再付与する前に切れ始めるため、8～10スタック以上を維持することは困難です。シャドーウィーゼルの使い魔とDOT持続ダメージビルドの持続時間延長により、8スタックの維持は現実的です。DPSバーストビルドとヘモリッジを使用すると、クリムゾンスパイラル中に一時的に10～12スタックに達することがありますが、再発動する前にいくつかが切れてしまいます。

### 出血はベリーハードダンジョンのボスに有効ですか？

はい、出血はベリーハードのボスを含むすべてのボスに有効です。一部のベリーハードボスが部分的に耐性を持つ凍結とは異なり、現在のゲームバージョンでは出血に耐性メカニズムはありません。これにより、ロキシーはベリーハードコンテンツで独自の価値を持ちます。彼女は主要メカニズムがボスの耐性によって弱体化されることがない唯一のDPSヒーローです。ただし、一部のボスはフェーズ移行中にアクティブな状態異常を解除することがあり、これにより出血スタックがリセットされます。

### ロキシーにはどの使い魔を組み合わせるべきですか？

「シャドーウィーゼル」は、出血持続時間の延長がDPSバーストとDOT持続ダメージの両方に利益をもたらすため、両方のロキシービルドにとって最適な使い魔です。「スパイダー」の使い魔は、追加の毒DOTダメージが必要な場合のDOT持続ダメージビルドの状況に応じた代替案です。DPSバーストの場合、「インフェルノドレイク」はシグナルスキル発動時に攻撃力ボーナスを提供しますが、ロキシーのダメージは純粋なシグナルスキルダメージではなく主に出血のティックから発生するため、リュートほど影響は大きくありません。使い魔の場所については、[使い魔ガイド](/en/familiars/complete-familiar-guide/)を確認してください。

### ロキシーはスタンロックチームなしで機能しますか？

ロキシーは群衆制御なしでも機能しますが、プレイは著しく難しくなります。タッグパートナーからの凍結やノックダウンがない場合、ロキシーは出血を付与しながら敵の攻撃を回避しなければならず、攻撃の連続が中断され出血の発動が遅れます。ソロプレイや非スタンロックチームでは、出血持続時間が長いため、スタックを失うことなく回避する柔軟性が増すDOT持続ダメージビルドの方がDPSバーストより安全です。チーム編成の詳細については、[チーム編成ガイド](/en/guides/team-composition-guide/)を参照してください。
